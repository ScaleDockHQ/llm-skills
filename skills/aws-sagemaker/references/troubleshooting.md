# SageMaker troubleshooting

> Verified against Amazon SageMaker AI Developer Guide pages realtime-endpoints-deploy-models, endpoint-auto-scaling-zero-instances, serverless-endpoints, async-inference, AWS CLI v2.37.12 sagemaker list-endpoints reference; LMI starting guide and chat schema, LiteLLM aws_sagemaker docs, 2026-10-11

Start with `aws sagemaker describe-endpoint --endpoint-name <name> --query '{S:EndpointStatus,F:FailureReason}'` and the endpoint CloudWatch log group (unverified name: `/aws/sagemaker/Endpoints/<name>`).

| Symptom                                                                                 | Cause                                                                            | Fix                                                                                                                                                                       |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Endpoint `Failed`                                                                       | Container did not become healthy, model download timed out, no capacity          | Read `FailureReason` and CloudWatch logs; raise health-check and download timeouts for big models; delete and recreate (only `DeleteEndpoint` works on a failed endpoint) |
| `ResourceLimitExceeded` creating the endpoint (error name unverified in the pages read) | Instance-type quota for endpoint usage is zero or used                           | Service Quotas request for that instance type and Region, or another type or Region                                                                                       |
| `AccessDenied` creating resources in Studio                                             | IAM policy allows create but not tagging                                         | Add permission to tag SageMaker resources                                                                                                                                 |
| Container exits at start, OOM or CUDA out of memory                                     | Weights plus KV cache exceed GPU memory                                          | Larger instance, higher `TENSOR_PARALLEL_DEGREE`, quantized model (`model-quantization`), smaller context                                                                 |
| Gated model download 401 or 403                                                         | `HF_TOKEN` missing or no access                                                  | Set `HF_TOKEN` from a secret store and accept the model license                                                                                                           |
| Model works with `inputs` but chat payload fails                                        | No chat template in the model or wrong route                                     | Use a model with a chat template; use `sagemaker_chat/` in LiteLLM                                                                                                        |
| `ValidationError` converting real-time to serverless                                    | Not allowed                                                                      | Create a new serverless endpoint; note serverless has no GPUs                                                                                                             |
| Invocation error while scaled to zero                                                   | No instances yet (minutes to provision)                                          | Retry with backoff; check step policy and `NoCapacityInvocationFailures` alarm; keep one copy warm                                                                        |
| Async endpoint never scales up from zero                                                | Only the backlog target policy exists                                            | Add the `HasBacklogWithoutCapacity` step policy and alarm                                                                                                                 |
| Async request times out                                                                 | Default 15 minutes                                                               | Set `InvocationTimeoutSeconds` up to 3600                                                                                                                                 |
| Inline async body rejected                                                              | Over 128,000 bytes                                                               | Use S3 `InputLocation`                                                                                                                                                    |
| `temperature=0` fails through LiteLLM                                                   | SageMaker containers reject 0                                                    | LiteLLM rounds to 0.1; set `aws_sagemaker_allow_zero_temp: true` if safe                                                                                                  |
| Streaming looks chunked after the fact                                                  | `sagemaker/` route fakes streaming                                               | Use `sagemaker_chat/` and a container with streaming                                                                                                                      |
| Endpoint config deleted but endpoint still shows old instance type                      | Deleted a config in use                                                          | Recreate visibility with `update-endpoint`; delete configs only after the endpoint is gone                                                                                |
| Charges continue after delete                                                           | Another Region, an inference component, a second endpoint, or leftover S3 or NAT | Run the teardown verify commands in every Region; check Cost Explorer by resource                                                                                         |
| Autoscaling does nothing                                                                | Missing service-linked role or permissions                                       | Allow `iam:CreateServiceLinkedRole` and Application Auto Scaling permissions; check `describe-scaling-activities`                                                         |

Keep the endpoint name, Region, request time and request id when opening an AWS Support case.
