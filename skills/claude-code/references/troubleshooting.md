# Claude Code with self-hosted endpoints: troubleshooting

> Verified against Claude Code v2.1.296 (docs: llm-gateway-connect, llm-gateway-protocol, env-vars, model-config), 2026-10-11

Start with `scripts/check-endpoint.sh`. If it fails, the endpoint is the problem. If it passes and Claude Code still fails, use `/status`, `claude doctor` and `claude --debug` (log at `~/.claude/debug/<session-id>.txt`).

| Symptom                                                                                                    | Cause                                                                                                | Fix                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Login screen on start                                                                                      | No credential reached Claude Code                                                                    | Export `ANTHROPIC_AUTH_TOKEN` (even a dummy for keyless engines) or set `apiKeyHelper`; check `/status`.                                                                        |
| Login screen though curl works                                                                             | Credential is in a project `.claude/settings.json` env block, applied only after first-run and trust | Move it to a shell export or `~/.claude/settings.json`.                                                                                                                         |
| Startup warning naming two credential sources, `auth may not work as expected`                             | Gateway credential and a saved login both active                                                     | Unset the variable, or `/logout` to keep only the gateway credential.                                                                                                           |
| `ANTHROPIC_API_KEY` ignored with no prompt                                                                 | A previously declined key is skipped silently                                                        | Enable it under `/config` ("Use custom API key"), or use `ANTHROPIC_AUTH_TOKEN`.                                                                                                |
| `401`, invalid or unrecognized token                                                                       | Credential in the wrong header                                                                       | `ANTHROPIC_AUTH_TOKEN` is Bearer, `ANTHROPIC_API_KEY` is `x-api-key`; llama.cpp's Anthropic route wants `x-api-key`. Or revoked key.                                            |
| `404` on `/v1/v1/messages`                                                                                 | Base URL ends in `/v1`                                                                               | Use the root URL.                                                                                                                                                               |
| `404` on `/v1/messages`, or HTML back                                                                      | Endpoint is chat-only, or a proxy route is missing                                                   | Use an engine with Messages support or put LiteLLM in front. `API returned an empty or malformed response (HTTP 200)` means an HTML or login page came back.                    |
| `model not found`, `Invalid model`                                                                         | Alias differs from what the endpoint serves, or a slot still holds an Anthropic ID                   | List ids with `GET /v1/models` (see `models-and-limits.md`); set `ANTHROPIC_MODEL` and the Opus, Sonnet, Haiku and subagent slots.                                              |
| `Connection refused`, `ENOTFOUND`, long silent pause then error                                            | Wrong host, firewall, VPN, server down; Claude Code retries with backoff                             | Run the curl probe; check the service and path.                                                                                                                                 |
| `400 Extra inputs are not permitted`, unknown `anthropic-beta`, `context_management`                       | Backend rejects beta fields                                                                          | `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1`.                                                                                                                                     |
| `400` naming `thinking` / `adaptive`                                                                       | Backend or gateway does not accept adaptive reasoning                                                | Upgrade upstream, or `CLAUDE_CODE_DISABLE_THINKING=1`; Opus/Sonnet 4.6 only: `CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING=1`.                                                         |
| `400` context or token limit in the server's own words (`ContextWindowExceededError`, `exceeds the limit`) | Server window smaller than what Claude Code assumes; error wording unrecognized so no auto-compact   | `/compact`; set `CLAUDE_CODE_MAX_CONTEXT_TOKENS`, `CLAUDE_CODE_AUTO_COMPACT_WINDOW` and `CLAUDE_CODE_MAX_OUTPUT_TOKENS` to the server's real limits; raise the server's window. |
| Context overflows on Ollama while the model supports more                                                  | Ollama's context default is small                                                                    | `OLLAMA_CONTEXT_LENGTH=65536` or higher (engine skill `ollama`), then restart.                                                                                                  |
| Tool calls come back as text, edits never apply                                                            | Tool parser or chat template missing                                                                 | vLLM `--enable-auto-tool-choice --tool-call-parser`; llama.cpp `--jinja`; Ollama tools-capable model.                                                                           |
| Thinking text appears in the answer                                                                        | Engine reasoning parser not enabled or mapped                                                        | Fix on the engine (`--reasoning-parser` on vLLM, `--reasoning-format` on llama.cpp).                                                                                            |
| Response stalls then `The response above may be incomplete`, or stops mid-stream                           | Proxy buffers SSE, strips `ping`, or cuts idle connections                                           | Disable buffering; keep pings; raise proxy and `API_TIMEOUT_MS` timeouts.                                                                                                       |
| First request after idle fails or times out                                                                | llama-swap or Ollama loading the model                                                               | Raise `API_TIMEOUT_MS`; keep the model warm (`keep_alive`, llama-swap `ttl`).                                                                                                   |
| Models missing from `/model`                                                                               | Discovery off, IDs lack `claude`/`anthropic`, `/v1/models` redirects or is slow                      | `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` and aliases containing `claude`, or `ANTHROPIC_CUSTOM_MODEL_OPTION`; see `[gatewayDiscovery]` in `--debug`.                      |
| `403` HTML body, endpoint logs show nothing                                                                | WAF or reverse proxy blocked the request body                                                        | Exempt `/v1/messages` from body inspection (AWS WAF `CrossSiteScripting_Body`, ModSecurity CRS).                                                                                |
| `SSL certificate verification failed` though curl works                                                    | Claude Code's runtime does not trust the CA curl uses                                                | `NODE_EXTRA_CA_CERTS=/path/ca.pem`.                                                                                                                                             |
| `/fast` unavailable, WebFetch domain check fails                                                           | Those calls go to `api.anthropic.com` directly                                                       | Allow the host or `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS=1`, `skipWebFetchPreflight: true`.                                                                                 |
| `Your apiKeyHelper script is failing`                                                                      | Helper prints nothing, a banner or errors                                                            | Run it by hand: it must print only the key.                                                                                                                                     |
| Slow turns, high input tokens, no cache hits                                                               | Proxy flattens `system` or strips `cache_control`; backend has no prefix cache                       | Forward bodies unchanged; enable prefix caching on the engine.                                                                                                                  |
| Settings change ignored                                                                                    | Environment read at startup, or higher-precedence file wins                                          | Restart `claude`; check `claude doctor` and the precedence order.                                                                                                               |

Escalate with: Claude Code version, the exact error, `/status` output with the key redacted, endpoint engine and version, and whether `scripts/check-endpoint.sh` passed.
