# LlamaIndex: troubleshooting

> Verified against LlamaIndex llama-index v0.14.25 (llama-index-core 0.14.25, llama-index-llms-openai-like 0.8.1, llama-index-llms-anthropic 0.12.2, llama-index-llms-ollama 0.11.0), 2026-10-11

First reproduce outside LlamaIndex: `BASE_URL=... MODEL=... KEY_FILE=... scripts/probe.sh openai` (or `anthropic`). If curl works and LlamaIndex fails, suspect the class, the capability flags or the embedding default.

| Symptom                                                                  | Likely cause and fix                                                                                                                                                                                           |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ValueError: Unknown model ...` listing OpenAI model names               | The `OpenAI` class was used with a custom alias. Switch to `OpenAILike` and set `context_window`.                                                                                                              |
| Asks for `OPENAI_API_KEY` or "Could not load OpenAI model" at index time | `Settings.llm` or `Settings.embed_model` is unset, so the OpenAI default was resolved. Set both explicitly (`OpenAILikeEmbedding` for embeddings).                                                             |
| 404 or odd prompt formatting on every call                               | `OpenAILike` left at `is_chat_model=False`, so it calls `/v1/completions`. Set `is_chat_model=True`. Also check the base URL ends in `/v1`.                                                                    |
| 404 on every call with `Anthropic`                                       | Base URL given with `/v1`; the Anthropic SDK adds it. Use the root URL.                                                                                                                                        |
| `LLM must be a FunctionCallingLLM` from `FunctionAgent`                  | `is_function_calling_model` is false (the `OpenAILike` default). Set it true only when the engine returns tool calls; otherwise use `ReActAgent`.                                                              |
| Agent never calls tools, tool JSON appears in text                       | Engine lacks a tool parser: vLLM `--enable-auto-tool-choice --tool-call-parser`, llama-server `--jinja`, Ollama model without tool support.                                                                    |
| Answers cut off or "context too long" with big prompts                   | `context_window` default is 3900 on `OpenAILike`; set the model's real window. The engine's own limit must be at least as large.                                                                               |
| Validation errors from `structured_predict`                              | Model returned prose or wrapped JSON. Try `should_use_structured_outputs=True` only if the engine enforces `json_schema`; else mark the model non-function-calling to use the text program; lower temperature. |
| Ollama: `ReadTimeout` on first call                                      | `request_timeout` defaults to 30 s and a cold load exceeds it. Raise it.                                                                                                                                       |
| Ollama: out of memory or very slow                                       | `context_window=-1` sends the model's maximum as `num_ctx`. Set a realistic `context_window`.                                                                                                                  |
| Streamed usage is missing                                                | Not requested by default. Add `additional_kwargs={"stream_options": {"include_usage": True}}`; the engine must honor it.                                                                                       |
| 401 with a real key leaking to your server                               | Ambient `OPENAI_API_KEY` or `OPENAI_API_BASE` was picked up. Pass `api_key` and `api_base` explicitly.                                                                                                         |
| 401 on `Anthropic` but curl with Bearer works                            | The gateway wants `Authorization: Bearer`; pass `default_headers`.                                                                                                                                             |
| `model not found` / 400 on model                                         | Using the repo id, not the alias from `/v1/models` (vLLM `--served-model-name`, LiteLLM `model_name`, llama-swap key, Ollama tag).                                                                             |
| Retrieval quality collapses after changing the embedding model           | Index and query embeddings must match; re-index after changing `embed_model`.                                                                                                                                  |
| Embedding calls fail with 400 on batch size or input length              | Lower `embed_batch_size` (default 10) and chunk size; check the embedding server's max input length.                                                                                                           |
| `SSLError` certificate verify failed                                     | Private CA: set `SSL_CERT_FILE=/path/ca.pem` or pass `http_client=httpx.Client(verify=...)` to `OpenAILike`. Do not disable verification.                                                                      |
| `<think>` in answers or empty content                                    | Reasoning parser off, or thinking consumed `max_tokens`; enable the parser, raise `max_tokens`, disable thinking.                                                                                              |
| Duplicate slow requests after a timeout                                  | `max_retries` defaults to 3 on `OpenAILike`; lower it for local models.                                                                                                                                        |
| Import errors after upgrade                                              | Mixed majors of `llama-index-core` and integration packages. Upgrade them together; see `updating.md`.                                                                                                         |
