# Speaches: troubleshooting

> Verified against Speaches master source and docs (troubleshooting.md, routers, dependencies.py), 2026-10-11

| Symptom                                          | Likely cause                                                             | Fix                                                                                                                                                            |
| ------------------------------------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `uvx: command not found` inside the container    | the CLI belongs on the host (upstream troubleshooting page)              | run `uvx speaches-cli ...` on the host, or skip it and call the HTTP routes with curl (`models.md`)                                                            |
| `uvx speaches-cli` fails on Python version       | PyPI package requires Python `==3.12.*` and was last released 2025-03-24 | use curl against `/v1/models`, `/v1/registry`                                                                                                                  |
| HTTP 403 `API key required` or `Invalid API key` | `API_KEY` is set; Speaches answers 403, not 401                          | send `Authorization: Bearer <key>`; `/health` stays public                                                                                                     |
| Model not found / 404 on a request               | model not downloaded, or wrong repo id                                   | `POST /v1/models/<id>` first; list with `GET /v1/models`; check `GET /v1/registry?task=...`                                                                    |
| Download returns 401 `gated repository`          | gated Hugging Face repo                                                  | set `HF_TOKEN` in the container environment (env file), accept the model terms on the Hub                                                                      |
| Container exits at start                         | `PRELOAD_MODELS` entry missing or failed to download                     | fix the id or network, or remove `PRELOAD_MODELS`; read `docker logs`                                                                                          |
| Runs on CPU although `--gpus=all` was passed     | CPU image, or NVIDIA container toolkit missing                           | use `latest-cuda`; `docker run --rm --gpus all nvidia/cuda:12.6.3-base-ubuntu24.04 nvidia-smi` should list the GPU; with CDI use `--device=nvidia.com/gpu=all` |
| `WHISPER__...` setting ignored                   | single underscore or wrong nesting                                       | nested fields use a double underscore, e.g. `WHISPER__COMPUTE_TYPE=int8_float16`                                                                               |
| Timestamps look shifted or segments empty        | VAD filter and `without_timestamps=true` default                         | send `-F without_timestamps=false`, use `verbose_json`; see `configuration.md` on `_unstable_vad_filter`                                                       |
| Word timestamps missing                          | wrong form key or format                                                 | `-F 'timestamp_granularities[]=word' -F response_format=verbose_json`                                                                                          |
| First request very slow                          | model load after idle unload                                             | raise `STT_MODEL_TTL`/`TTS_MODEL_TTL`, or warm with `POST /api/ps/<id>`                                                                                        |
| TTS audio plays garbled in a client              | wrong `response_format` or writing JSON as audio                         | the body is raw audio; use `-o file`; pick the format your player supports                                                                                     |
| Voice not found                                  | TTS model not downloaded or voice name wrong                             | `GET /v1/audio/voices`; Kokoro voices such as `af_heart`                                                                                                       |
| Open WebUI STT stays on the old engine           | UI setting overrides env vars (upstream warning)                         | change it in Admin Settings, Audio                                                                                                                             |
| Realtime session fails immediately               | default STT or TTS model not downloaded                                  | download `Systran/faster-distil-whisper-small.en` and `speaches-ai/Kokoro-82M-v1.0-ONNX` (`realtime.md`)                                                       |
| Realtime transcribes its own TTS                 | speakers feeding the mic (upstream limitation)                           | use a headset                                                                                                                                                  |
| 502 or timeout through a proxy on long files     | synchronous request exceeds proxy read timeout                           | `stream=true`, split audio, raise proxy timeouts, or stay private                                                                                              |
| Unexpected exposure of the API or UI             | `--publish 8000:8000` binds all interfaces                               | republish on `127.0.0.1:8000`, set `API_KEY`, `ENABLE_UI=false`                                                                                                |

Read logs with `docker logs -f speaches`; `LOG_LEVEL=debug` is the default and is chatty. Error bodies include an `error_id` you can grep for in the log.
