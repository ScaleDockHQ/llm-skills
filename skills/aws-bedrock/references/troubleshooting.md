# Bedrock troubleshooting

> Verified against Amazon Bedrock User Guide pages troubleshooting-api-error-codes, model-access, inference-chat-completions, endpoints, api-keys, vpc-interface-endpoints, quotas-runtime, 2026-10-11

| Symptom                                                          | Cause                                                                                                                                | Fix                                                                                                                                                                                |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AccessDeniedException` (403)                                    | Missing IAM action; expired temporary credentials; model subscription not finished; extra account-level access needed                | Check `aws sts get-caller-identity`, grant `bedrock:InvokeModel` on the model or profile ARN, check `get-foundation-model-availability`, then contact AWS if prerequisites are met |
| `AccessDeniedException` after first calls worked                 | Background Marketplace subscription failed (missing `aws-marketplace:Subscribe`, `Unsubscribe`, `ViewSubscriptions`, payment method) | Add permissions, wait up to 2 minutes (subscription up to 15)                                                                                                                      |
| `FTUFormNotFilled` (404)                                         | Anthropic use-case form not submitted                                                                                                | `put-use-case-for-model-access` or console; poll `agreementAvailability` until `AVAILABLE`                                                                                         |
| `MPAgreementBeingCreated` (403)                                  | Marketplace subscription still processing                                                                                            | Retry after 15 minutes                                                                                                                                                             |
| AWS Marketplace Agreement failed within 15 minutes               | Invalid payment or restricted geography                                                                                              | Fix the payment method; see AWS Marketplace payment guidance                                                                                                                       |
| `ThrottlingException` (429)                                      | Account quota exceeded                                                                                                               | Backoff with jitter, read `service-quotas`, cross-Region profile, request increase, Provisioned Throughput or Reserved Tier                                                        |
| `ServiceUnavailable` (503)                                       | Capacity, not your quota                                                                                                             | Retry with backoff, try another Region or cross-Region profile                                                                                                                     |
| `overloaded_error` (529)                                         | Model temporarily out of capacity                                                                                                    | Retry with jitter, honor `Retry-After`, use cross-Region                                                                                                                           |
| `ResourceNotFound` (404)                                         | Wrong model ID, profile ID or Region                                                                                                 | `list-foundation-models` and `list-inference-profiles` in that Region                                                                                                              |
| `ValidationError` (400)                                          | Bad parameters; model requires an inference profile ID rather than the base ID                                                       | Check the API reference and the model card; use the profile ID                                                                                                                     |
| `IncompleteSignature`, `InvalidClientTokenId`, `RequestExpired`  | Bad credentials or clock skew                                                                                                        | Check access key, sync system clock, update SDK                                                                                                                                    |
| `Credential should be scoped to a valid region`                  | Long-term API key used in another Region                                                                                             | Generate the key in the Region you call                                                                                                                                            |
| `404 UnknownOperationException` on `/models`                     | `bedrock-runtime` lacks the Models API                                                                                               | Use `list-foundation-models`, or the `bedrock-mantle` base URL                                                                                                                     |
| `model <id> isn't supported on this route`                       | Wrong path prefix on `bedrock-mantle` (`/v1` vs `/openai/v1`)                                                                        | Check the model card's Programmatic Access table                                                                                                                                   |
| 400 on `background=true` or app inference profile with Responses | Not supported on `bedrock-runtime`                                                                                                   | Use `bedrock-mantle`, or a system profile                                                                                                                                          |
| 400 on `output_config.format`                                    | Structured outputs unsupported on `bedrock-mantle` Messages API                                                                      | Use Converse or InvokeModel on `bedrock-runtime`                                                                                                                                   |
| Request fails though your policy allows the Region               | SCP blocks a destination Region of a cross-Region profile                                                                            | Allow all destination Regions (global: `aws:RequestedRegion` = `unspecified`)                                                                                                      |
| Connection reset or 70 second first call after idle              | NAT gateway, interface VPC endpoint or NLB idle timeout of 350 s                                                                     | Enable SDK TCP keep-alive (boto3 `Config(tcp_keepalive=True)`) and set `net.ipv4.tcp_keepalive_time` below 350 (for example 45)                                                    |
| Quota increase denied                                            | Model Legacy or Deprecated, or existing quota underused                                                                              | Migrate to the successor model; build usage first                                                                                                                                  |
| Imported model import job fails                                  | Unsupported architecture, weights over limit, wrong transformers version                                                             | Check supported architectures, 200 GB text limit, transformers 4.51.3                                                                                                              |
| LiteLLM `AuthenticationError` for Bedrock                        | No credentials in the gateway process                                                                                                | Instance role or `AWS_PROFILE`, or `api_key: os.environ/AWS_BEARER_TOKEN_BEDROCK`; check env var names only                                                                        |

Always include request ID, model ID, Region and time when contacting AWS Support. Docs: https://docs.aws.amazon.com/bedrock/latest/userguide/troubleshooting-api-error-codes.html
