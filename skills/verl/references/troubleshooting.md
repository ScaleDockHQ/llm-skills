# Troubleshooting verl

> Verified against verl-project/verl v0.9.1 (docs/faq/faq.rst, docs/start/install.rst, docs/perf/perf_tuning.rst), 2026-10-11

| Symptom                                                                                      | Cause and fix                                                                                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Unable to register worker with raylet`                                                      | Slurm CPU constraints. Set `ray_kwargs.ray_init.num_cpus` to an allowed number.                                                                                                                                                                                                                                                         |
| `NotImplementedError: TensorDict does not support membership checks with the \`in\` keyword` | No suitable `tensordict` wheel on linux-arm64: build tensordict (e.g. v0.6.2) from source, per FAQ.                                                                                                                                                                                                                                     |
| `CUDA error: an illegal memory access was encountered` during rollout                        | Check the vLLM troubleshooting docs for your vLLM version; try a different engine version or `enforce_eager=True`.                                                                                                                                                                                                                      |
| Triton `compile_module_from_src` error                                                       | Disable JIT fused kernels: set `use_torch_compile=False` (see the config docs); make sure a C compiler and Python headers exist.                                                                                                                                                                                                        |
| `actor/grad_norm` keeps growing                                                              | Train/inference precision mismatch. Set `actor_rollout_ref.rollout.calculate_log_probs=True` and read `training/rollout_probs_diff_mean` (normal < 0.005, a problem > 0.01). Documented trigger: non-Hopper GPU, vLLM issue 22103, long outputs. Workaround: `+actor_rollout_ref.rollout.engine_kwargs.vllm.disable_cascade_attn=True`. |
| OOM in rollout                                                                               | Lower `rollout.gpu_memory_utilization` (0.4 to 0.6), lower `tensor_model_parallel_size` only if memory allows, set `enforce_eager=True` or small `cudagraph_capture_sizes`.                                                                                                                                                             |
| OOM in actor update                                                                          | `ppo_micro_batch_size_per_gpu=1`, gradient checkpointing, `use_dynamic_bsz` with a smaller `ppo_max_token_len_per_gpu`, `param_offload` / `optimizer_offload`, activation offload.                                                                                                                                                      |
| Ray workers use a different env from the driver under uv                                     | Set `ray_kwargs.ray_init.runtime_env.py_executable` to the same `uv run ...` prefix or an absolute interpreter path.                                                                                                                                                                                                                    |
| Ray >= 2.47 crash on `working_dir=None`                                                      | verl sets `RAY_ENABLE_UV_RUN_RUNTIME_ENV=0` itself; do not override it.                                                                                                                                                                                                                                                                 |
| uv reinstalls torch on each command                                                          | Extras differ between commands. Use identical `--extra` sets in one job.                                                                                                                                                                                                                                                                |
| Old vLLM unusable                                                                            | Docs: vLLM >= 0.18.0 required in current docs. Match the pins in `pyproject.toml` of your tag.                                                                                                                                                                                                                                          |
| Reward stuck at 0                                                                            | Answer extraction does not match model output (`references/rewards.md`).                                                                                                                                                                                                                                                                |
| Wrong batch behaviour                                                                        | Train and mini batch sizes are global; micro sizes are per GPU.                                                                                                                                                                                                                                                                         |

Debugging distributed Ray code: Ray distributed debugger (see Ray docs). Timeline: `ray_init.timeline_json_file=/tmp/ray_timeline.json`, open in chrome://tracing or Perfetto.

## Discovery

```bash
ray status; ls /tmp/ray/session_latest/logs | head
nvidia-smi --query-gpu=memory.used,memory.total --format=csv
grep -E 'rollout_probs_diff|grad_norm' verl_*.log | tail -5
```
