# Inspect AI: troubleshooting

> Verified against inspect-ai 0.3.278 (docs: options, providers, model-graded, handling-errors, eval-logs, caching), 2026-10-11

| Symptom                                                     | Cause                                                        | Fix                                                                                                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `inspect: command not found` or install fails on old Python | Not in the venv, or Python < 3.10                            | Activate the venv; use Python 3.10+ (3.11 for inspect-evals)                                                                         |
| `ModuleNotFoundError: openai` (or anthropic, google)        | Provider SDK is a separate package                           | `pip install openai` in the same venv                                                                                                |
| Auth error or "api key not set"                             | Wrong env var name for the provider                          | `vllm`: `VLLM_API_KEY`; `openai-api/<name>/`: `<NAME>_API_KEY` with hyphens as underscores; `litellm-proxy`: `LITELLM_PROXY_API_KEY` |
| Connection refused to localhost                             | Server down, or wrong `*_BASE_URL` (missing `/v1`)           | `curl $BASE/models`; include `/v1`                                                                                                   |
| Inspect starts a vLLM server instead of using yours         | `VLLM_BASE_URL` not exported                                 | Export it or pass `--model-base-url`                                                                                                 |
| Model id not found                                          | Served name differs from the model string                    | Use the id from `/models` after the provider prefix                                                                                  |
| LiteLLM proxy model fails creating the model                | Opaque deployment name, no context window known              | Add `model_info.base_model` in the proxy config                                                                                      |
| Judge scores look suspiciously high                         | No grader role bound, candidate graded itself                | `--model-role grader=...`; use `ModelRole("grader", required=True)`                                                                  |
| Grades never parse                                          | Custom `instructions` without matching `grade_pattern`       | Update `grade_pattern`                                                                                                               |
| `match()` scores zero on correct answers                    | Thinking text or trailing text in output                     | Reasoning parser on the server, `match(location="any")`, or `pattern()`; read transcripts                                            |
| Eval stops on first sample error                            | Default `fail_on_error` is true                              | `--fail-on-error 0.05` or `--retry-on-error=2`, then check the retried samples                                                       |
| `eval-retry` cannot rebuild the task                        | Task not created from an `@task` function                    | Wrap in `@task`; use plain-typed parameters                                                                                          |
| Rate-limit storms, slow backoff                             | Concurrency above the tier                                   | Lower `--adaptive-connections`/`--max-connections`; `--max-retries`                                                                  |
| Server queue timeouts                                       | Concurrency above server capacity                            | Lower connection ceiling; raise `--timeout` / `--attempt-timeout`                                                                    |
| Same outputs across "different" runs                        | `--cache` on, or aliased model name                          | Drop `--cache` for decision runs; use versioned names                                                                                |
| Can't read a `.eval` log with `jq`                          | Binary format                                                | `inspect log dump <file> \| jq ...`                                                                                                  |
| Perplexity scorer errors                                    | Streaming on, or no prompt logprobs                          | `--prompt-logprobs 1`, disable streaming                                                                                             |
| `math()` import error                                       | Optional deps missing                                        | `pip install "inspect-ai[math]"`                                                                                                     |
| Docker sandbox fails at startup                             | Docker not running, image missing under `--sandbox-prebuilt` | Start Docker; build images (with approval) or drop the flag                                                                          |
| Log viewer shows blank criterion                            | Sample has no `target`                                       | Map a `target` field with `FieldSpec`                                                                                                |

Debug aids: `--log-level http` shows HTTP traffic (can include prompts), `--debug-errors` raises task errors, `--display plain|log` for CI. Do not use `--traceback-locals` on shared logs; it can leak API keys.

Official sources: https://inspect.aisi.org.uk/options.html, https://inspect.aisi.org.uk/handling-errors.html
