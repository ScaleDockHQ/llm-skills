# faster-whisper: troubleshooting

> Verified against faster-whisper v1.2.1 README and source, CTranslate2 4.8.2, 2026-10-11

| Symptom                                                                          | Likely cause                                                  | Fix                                                                                                                               |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `Could not load library libcudnn_ops...` or `libcublas.so.12 not found`          | cuBLAS (CUDA 12) or cuDNN 9 missing or not on the loader path | install them or use the NVIDIA CUDA runtime image; for pip wheels set `LD_LIBRARY_PATH` **before** starting Python (`install.md`) |
| CUDA works in other tools but not here                                           | CTranslate2 build expects CUDA 12 and cuDNN 9                 | match the stack, or pin `ctranslate2==4.4.0` (CUDA 12, cuDNN 8) or `3.24.0` (CUDA 11, cuDNN 8) per README                         |
| CTranslate2 error that the device does not support efficient float16 computation | CPU or old GPU                                                | use `compute_type="int8"` on CPU, `float32` or `int8_float32` on older GPUs; check `get_supported_compute_types`                  |
| `transcribe()` returns instantly and output is empty                             | `segments` is a lazy generator that was never consumed        | iterate it or call `list(segments)`                                                                                               |
| Out of memory on GPU                                                             | large model, batching or several workers                      | `compute_type="int8_float16"`, smaller `batch_size`, fewer `num_workers`, smaller model                                           |
| Repeated phrases or runaway looping text                                         | `condition_on_previous_text=True` carries errors forward      | set it `False`, enable `vad_filter=True`, optionally `hallucination_silence_threshold` with `word_timestamps=True`                |
| Text appears over silence ("Thank you.", subtitles credit)                       | Whisper hallucination on silence                              | `vad_filter=True` and tune `vad_parameters`, raise `no_speech_threshold`                                                          |
| Wrong language or translated output                                              | auto-detection on a short or noisy clip                       | set `language="xx"`; check `info.language_probability`; `task="transcribe"`                                                       |
| Slower than expected on CPU                                                      | too few threads or float32                                    | `compute_type="int8"`, `cpu_threads=<physical cores>` or `OMP_NUM_THREADS`                                                        |
| Downloads fail or hang on a server                                               | no network or gated repo                                      | pre-download and use `local_files_only=True`, or `download_root=`; authenticate with `HF_TOKEN` from the environment              |
| `onnxruntime` errors at `vad_filter=True`                                        | missing or conflicting `onnxruntime` build                    | `pip install 'onnxruntime>=1.14,<2'` in the same environment (it is a declared dependency)                                        |
| Word timestamps missing                                                          | `word_timestamps` is off by default                           | pass `word_timestamps=True`                                                                                                       |
| `distil-large-v3` output degrades on long audio                                  | needs its recommended settings                                | `language="en"`, `condition_on_previous_text=False`, `beam_size=5` (README example)                                               |

Enable debug logs with `logging.getLogger("faster_whisper").setLevel(logging.DEBUG)`.
