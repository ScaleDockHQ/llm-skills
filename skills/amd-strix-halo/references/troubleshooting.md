# Troubleshooting

> Verified against strix-halo-toolboxes.com host guide, kyuz0/amd-strix-halo-toolboxes README, Strix Halo Wiki AI overview (2025-08), ROCm 10.1.0 release notes, 2026-10-11

| Symptom                                                                       | Likely cause                                                     | Fix                                                                                                                                                              |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Only about half of RAM is usable by the GPU, or a model does not fit          | TTM limit left at the default, or a conflicting `amdgpu.gttsize` | Check `mem_info_gtt_total`; set `ttm.pages_limit` (`memory.md`); keep one source of truth; reboot.                                                               |
| Load hangs for minutes or hours on a large model                              | mmap, especially with ROCm                                       | Disable mmap (`-lm none` or `--no-mmap`); check the TTM limit.                                                                                                   |
| Crashes or slowdowns on ROCm builds                                           | Flash attention off, or mmap on                                  | Use `-fa on` (or `-fa 1`) and no mmap, as the toolbox README requires.                                                                                           |
| Inference failures on ROCm builds in llama.cpp with host buffers              | llama.cpp issue 25992                                            | Use the toolbox image that carries the workaround, or update llama.cpp when the upstream fix lands.                                                              |
| `llama-cli --list-devices` shows no GPU in a container                        | Missing device flags                                             | Vulkan: `--device /dev/dri --group-add video`. ROCm: also `--device /dev/kfd --group-add render`, plus `--security-opt seccomp=unconfined` per the toolbox docs. |
| `Permission denied` on `/dev/kfd`                                             | User not in `render` and `video`                                 | `sudo usermod -a -G render,video "$LOGNAME"` and log out and in; the udev rule alternative opens the GPU to all users.                                           |
| `toolbox create` fails on Ubuntu or Debian                                    | Toolbx permission issues on those distros                        | Use Distrobox.                                                                                                                                                   |
| NPU device (`/dev/accel/accel0`) disappeared                                  | `amd_iommu=off`                                                  | Re-enable the IOMMU if you need the NPU.                                                                                                                         |
| System freezes or the OOM killer fires while serving                          | Pool set too close to total RAM                                  | Lower `ttm.pages_limit`; stop the desktop (`multi-user.target`); leave headroom for the OS.                                                                      |
| Prompt processing slower than expected                                        | Default CPU idle states, or wrong backend                        | Apply the `accelerator-performance` tuned profile; compare RADV Vulkan and ROCm with `llama-bench`.                                                              |
| ROCm install on Ubuntu 24.04 does not see the GPU                             | Kernel too old                                                   | Use the matrix kernel (HWE 7.0 or GA 7.0 on 26.04.1); AMD's page names OEM kernel 6.14 as a minimum on 24.04.                                                    |
| Ollama is slow or does not use the GPU                                        | Historical AMD and Vulkan gaps                                   | Check the current Ollama notes and the `ollama` skill; the wiki advised against Ollama in 2025-08.                                                               |
| Lemonade ROCm backend downloads gigabytes at first model load after an update | ROCm 10 runtime refresh in v2026.41.1                            | Expected; wait.                                                                                                                                                  |
| `amd-smi event` hangs                                                         | Not supported on WSL                                             | Do not run it on WSL.                                                                                                                                            |

Collect for a bug report: `uname -r`, `cat /proc/cmdline`, `cat /sys/class/drm/card*/device/mem_info_gtt_total`, `dmesg | grep -i amdgpu`, `vulkaninfo --summary`, `rocminfo | grep gfx` and the engine's startup log. Remove tokens and hostnames you do not want to share.
