# Troubleshooting

> Verified against Caddy v2.11.7 (docs: reverse_proxy, global options, forward_auth; Ollama server/routes.go at v0.40.3; local tests with Caddy v2.11.7), 2026-10-11

First look: `systemctl status caddy`, `journalctl -u caddy -n 50 --no-pager`, `caddy validate --config <file> --adapter caddyfile`, and the backend directly (`curl -sS http://127.0.0.1:<port>/health`).

| Symptom                                                       | Cause                                                                                                                                                                           | Fix                                                                                                  |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Tokens arrive in one burst                                    | buffering somewhere: missing `flush_interval -1`, `request_buffers`/`response_buffers` set, a tunnel that buffers non-SSE types (Cloudflare buffers unless `text/event-stream`) | `flush_interval -1`; remove buffers; test each hop with `curl -N`                                    |
| 502 Bad Gateway                                               | engine down, wrong port, engine bound to another address, upstream closed an idle keep-alive connection                                                                         | `ss -tlnp`; `curl` the upstream; keep `transport http { keepalive }` below the engine's idle timeout |
| 403 Forbidden from Ollama only through the proxy              | Ollama rejects a Host that is not localhost, a loopback or private IP, this host's name, or `*.local`/`*.internal`/`*.localhost`                                                | `header_up Host {upstream_hostport}` (`assets/Caddyfile.ollama-guard`)                               |
| 401 on `/v1/models` through the catalog front                 | key rejected by the gateway (correct), or key missing                                                                                                                           | send `Authorization: Bearer <key>`                                                                   |
| 401 from the guard matcher                                    | token differs, or `OLLAMA_PROXY_TOKEN` empty because the env file was not loaded                                                                                                | check `EnvironmentFile`, restart (reload does not re-read the environment)                           |
| Clients still show the thin model list                        | `/v1/models` bypasses Caddy (catch-all above the path rule), stale `models.json`                                                                                                | fix rule order; rerun `build-catalog.sh`                                                             |
| `connection reset by peer` on some requests                   | Caddy keep-alive to HTTP/1.1 upstream longer than the upstream's                                                                                                                | lower `keepalive` or raise the engine's idle timeout                                                 |
| Large image prompts get 413                                   | `request_body { max_size }` too small                                                                                                                                           | raise it; match the gateway's limit                                                                  |
| Long upload aborts after about 1 minute                       | `read_body_idle` default `1m` and the client stalled                                                                                                                            | fix the network, or raise `read_body_idle`                                                           |
| Stream cut after a config reload                              | WebSockets and streams on the old config are closed on reload                                                                                                                   | `stream_close_delay 5m`; avoid reloads during runs                                                   |
| ACME failures on a public name                                | ports 80/443 not reachable or DNS wrong                                                                                                                                         | open ports, fix DNS, read the journal                                                                |
| `:8088` tries to get certificates                             | `auto_https off` missing                                                                                                                                                        | set it in the global block                                                                           |
| `address already in use`                                      | another Caddy or the system Caddy on the same port                                                                                                                              | `ss -tlnp`; pick another port                                                                        |
| `caddy reload` fails with connection refused                  | admin API disabled (`admin off`) or different address                                                                                                                           | `systemctl restart caddy`                                                                            |
| Real client IP shows `127.0.0.1`                              | proxies in front not trusted                                                                                                                                                    | `servers { trusted_proxies static private_ranges }` and `client_ip_headers`                          |
| Formatting warning "Caddyfile input is not formatted"         | tabs or alignment                                                                                                                                                               | `caddy fmt --overwrite <file>`                                                                       |
| `Incremental` request or response gets 501 (v2.11.7 or later) | buffering configured on a message marked incremental                                                                                                                            | remove `request_buffers`/`response_buffers`                                                          |

## Collect before asking for help

`caddy version`, `caddy adapt --config <file>` (check for secrets first), 30 journal lines, and `curl -v` output without `Authorization` lines.
