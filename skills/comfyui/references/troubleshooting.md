# ComfyUI: troubleshooting

> Verified against ComfyUI v0.39.0 (README troubleshooting, server.py, cli_args.py, nodes.py), llama-swap v263 (comfyui guide) and ComfyUI-Manager README, 2026-10-11

Start with evidence: the server log (stderr, or `journalctl --user -u comfyui`), `GET /system_stats`, `GET /queue` and `GET /history/{id}`.

| Symptom                                                                      | Likely cause and fix                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Torch not compiled with CUDA enabled`                                       | CPU-only torch got installed. README fix: `pip uninstall torch`, then reinstall with `pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130` (`install.md`).                                                                                             |
| `torch.cuda.is_available()` is `False` on NVIDIA                             | driver older than the cu130 build needs (README: update NVIDIA drivers), wrong venv active, or a CPU wheel. Check `nvidia-smi` and `python -c 'import torch;print(torch.__version__)'`.                                                                                                              |
| Browser or proxied UI gets HTTP 403, log says `non matching host and origin` | the origin-only middleware rejects a request whose `Host` is a loopback name but whose `Origin` differs, and any `Sec-Fetch-Site: cross-site`. Make the proxy pass the original `Host`, browse the same hostname you proxy, or avoid `--enable-cors-header *` as a shortcut (it disables the check). |
| `POST /prompt` returns 400 with `node_errors`                                | validation failed. Read `node_errors`: a missing model file, a bad value or a missing node class. Fix the named node's input.                                                                                                                                                                        |
| `POST /prompt` returns 400 `no_prompt`                                       | body lacks the `prompt` key. Send `{"prompt": <graph>}`, not the bare graph.                                                                                                                                                                                                                         |
| `POST /prompt` returns 400 `invalid_prompt_id`                               | `prompt_id` is not a lowercase hyphenated UUID. Omit it.                                                                                                                                                                                                                                             |
| Exported file is rejected or does nothing                                    | it is a UI-format workflow (`nodes`, `links`). Re-export with File, Export (API); `scripts/comfy-run.sh` refuses UI format early.                                                                                                                                                                    |
| `GET /history/{id}` returns `{}` forever                                     | job is still queued or running (check `GET /queue`), was cancelled, or the history limit evicted it. A finished job has `status.status_str` of `success` or `error`.                                                                                                                                 |
| `status_str` is `error`                                                      | read `status.messages`, then the log. Common: out of memory (below), missing model file, a custom node exception.                                                                                                                                                                                    |
| Out of memory during sampling or VAE decode                                  | lower resolution or batch; try `--cpu-vae` for decode OOM; raise `--reserve-vram` if another process shares the GPU; try `--disable-smart-memory`; on dynamic VRAM builds `--lowvram` does nothing (`performance-memory.md`).                                                                        |
| Black or noisy images                                                        | wrong text encoder or VAE for the model family, or `--fp16-vae` (help text warns of black images; try `--bf16-vae` or `--fp32-vae`). Match the files to the official template.                                                                                                                       |
| Missing nodes after loading a template                                       | ComfyUI older than the template, or a node failed to import. Look for `IMPORT FAILED` in the startup log; update (`updating.md`) or install the node (`custom-nodes.md`).                                                                                                                            |
| Custom node not loading on a server                                          | `--disable-all-custom-nodes` is set. Add `--whitelist-custom-nodes <folder>` for it.                                                                                                                                                                                                                 |
| Manager refuses an install or update                                         | `security_level` or `allow_git_url_install` / `allow_pip_install` in `config.ini` block it by design (`custom-nodes.md`). Do it from a shell with `comfy node install` after approval.                                                                                                               |
| UI or logs try to reach the internet on an offline host                      | start with `--offline`; the frontend comes from the pinned `comfyui-frontend-package`, so do not pass `--front-end-version` (it needs GitHub).                                                                                                                                                       |
| Model not listed in a loader dropdown                                        | wrong folder, wrong extension, or no restart after copying. Check `GET /models/<folder>` and the `extra_model_paths.yaml` log lines (`Adding extra search path ...`) (`models.md`).                                                                                                                  |
| Port in use or server unreachable                                            | `ss -ltnp \| grep 8188`; another instance (a stale background `comfy launch --background`?) holds it. Stop it with `comfy stop`.                                                                                                                                                                     |
| Reachable on the LAN unexpectedly                                            | `--listen` was passed with no value, which binds `0.0.0.0,::`. Use `--listen 127.0.0.1` and check `ss -ltnp`.                                                                                                                                                                                        |
| Slow first job, fast second                                                  | model load and cache warm-up. Measure the second run for steady state (`performance-memory.md`).                                                                                                                                                                                                     |
| Same graph returns instantly without new images                              | unchanged nodes are not re-executed (README). Change the seed.                                                                                                                                                                                                                                       |
| Python 3.14 custom node failures                                             | README: 3.14 works but some custom nodes break, try 3.13 or 3.12.                                                                                                                                                                                                                                    |

## Behind llama-swap

| Symptom                                          | Cause and fix (llama-swap comfyui guide)                                                                                                        |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `404 local model comfyui_auto not found`         | the model is not named exactly `comfyui_auto`, or it is defined on a peer. Aliases do not work for `/comfyui/`.                                 |
| ComfyUI never becomes ready                      | llama-swap's default `checkEndpoint` is `/health`, which ComfyUI does not serve. Set `checkEndpoint: /` (or `none`).                            |
| 409 `ignored ComfyUI paths cannot start it`      | a `GET` to `/ws`, `/api/jobs` or a static asset hit while the model is unloaded. Load `/comfyui/` first; queueing with `POST` starts the model. |
| 409 `ignored websocket requests cannot start it` | a stale browser tab reconnecting after unload. Interact with the page or close the tab.                                                         |
| Model unloads while a long render runs           | websocket traffic does not reset the TTL. Use a longer `ttl`, or `ttl: 0` and rely on swapping.                                                 |
| GPU memory stays used after unload               | Docker entry without `cmdStop`; add `cmdStop: docker stop <name>` and raise `unloadTimeout`.                                                    |
| An idle tab keeps the model loaded               | something the page polls is not in the ignored list. Close the tab or route through `/upstream/` with an `upstream.ignorePaths` entry.          |

Details and the full YAML are in `combos/llama-swap-litellm.md`.
