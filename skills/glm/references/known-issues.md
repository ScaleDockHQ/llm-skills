# GLM known issues and gotchas

> Verified against zai-org/GLM-5 GitHub issues (open as of 2026-10-11), vLLM and SGLang recipes, TensorRT-LLM GLM-5 guide, Unsloth guides, community GGUF and MLX cards, 2026-10-11

Sources: [zai-org/GLM-5 issues](https://github.com/zai-org/GLM-5/issues), [SGLang GLM-5.3](https://cookbook.sglang.io/autoregressive/GLM/GLM-5.3), [SGLang GLM-5.3-Flash](https://cookbook.sglang.io/autoregressive/GLM/GLM-5.3-Flash), [vLLM GLM-5.3-Flash](https://recipes.vllm.ai/zai-org/GLM-5.3-Flash), [Unsloth GLM-5.3-Flash](https://unsloth.ai/docs/models/glm-5.3-flash), [community GGUF card](https://huggingface.co/SixVolts/GLM-5.3-Flash-ewaste-edition-GGUF), [Run GLM-5.3-Flash locally guide](https://rohitghumare.com/guides/glm-5-3-flash/).

Issues quoted below are user reports on open GitHub issues, not confirmed by Z.ai. Many of the reports are against the hosted or Ollama-cloud endpoints, not local weights; they are listed because the same weights are behind them.

| Symptom                                                                                                             | Model and engine                                                                 | Cause or fix                                                                                                                                                                                 | Source                         |

| Tool call arrives as raw `<tool_call>` text in `content`, `finish_reason: "stop"`                                   | GLM-5.x, any                                                                     | Wrong or missing `--tool-call-parser`; use `glm47`                                                                                                                                           | SGLang cookbook                |
| Thinking and answer in one `content` string with a stray closing think tag                                          | any                                                                              | Add the reasoning parser                                                                                                                                                                     | SGLang cookbook                |
| `jinja2.exceptions.UndefinedError: 'str object' has no attribute 'items'` at `chat_template.jinja` line 163         | GLM-5.3-Flash, direct `apply_chat_template` with OpenAI-style string `arguments` | Template expects a dict; convert `arguments` with `json.loads` before rendering. SGLang's server normalises it, so not affected. Issue #158, open.                                           | GLM-5 issue 158                |
| Chinese tokens in English output; once whole output collapsed into multilingual garbage after long agentic sessions | GLM-5.3-Flash via Ollama cloud                                                   | Issues #142 and #163, open. The earlier identical bleed was reported on GLM-5.1. Mitigate with loop and garbage detectors in the harness; not confirmed on local weights.                    | GLM-5 issues 142, 163          |
| Planned command prefix dropped in the emitted tool call, repeating 10 times                                         | GLM-5.2 on Z.ai endpoint                                                         | Issue #116, open. Add a harness-side duplicate-call breaker.                                                                                                                                 | GLM-5 issue 116                |
| Quotes a system prompt it was never given on video input                                                            | GLM-5.3-Flash                                                                    | Issue #134, open.                                                                                                                                                                            | GLM-5 issue 134                |
| Flat ~3 s added to first token whenever `tools` is sent                                                             | glm-5.3-flash, Z.ai API                                                          | Issue #144, open; hosted API only as reported.                                                                                                                                               | GLM-5 issue 144                |
| `reasoning_content` not visible to the model across turns                                                           | any                                                                              | Issue #92 (zh), open. Preserve reasoning yourself: `clear_thinking=false` keeps prior thinking in the template.                                                                              | GLM-5 issue 92                 |
| `enable_thinking=false` has no effect                                                                               | GLM-5.3 / 5.3-Flash                                                              | There is no off switch; use `reasoning_effort: "low"`                                                                                                                                        | TensorRT-LLM guide             |
| Wrong effort level silently used                                                                                    | GLM-5.3                                                                          | Any value other than `low` or `high` becomes `max`; GLM-5.2 only accepts `high` and `max`                                                                                                    | GLM-5 README                   |
| Prefix cache re-prefills every turn                                                                                 | GLM-5.3 behind Claude Code                                                       | Template renders `tools` before `system`; set `CLAUDE_CODE_ATTRIBUTION_HEADER=0`                                                                                                             | SGLang cookbook                |
| Image requests answered from text only, no error                                                                    | GLM-5.3-Flash on SGLang                                                          | Old Transformers (5.12.1) loads only the tokenizer; need a build with `Glm5NextProcessor` (5.17.0, `tokenizers>=0.23.1`)                                                                     | SGLang cookbook                |
| Video requests fail                                                                                                 | GLM-5.3-Flash                                                                    | Install `torchcodec`                                                                                                                                                                         | SGLang cookbook                |
| Sparse-MLA init error                                                                                               | GLM-5.3-Flash on vLLM                                                            | FlashInfer older than 0.6.17 (recipe) or 0.6.18 (troubleshooting line)                                                                                                                       | vLLM recipe                    |
| Startup lowers `max_running_requests`                                                                               | GLM-5.3-Flash on SGLang                                                          | KDA state pool is the limit; raise `--mamba-full-memory-ratio` or set `--max-mamba-cache-size`; do not override `linear_lower_bound`                                                         | SGLang cookbook                |
| FP8 slow or failing                                                                                                 | GLM-5.3 on vLLM                                                                  | DeepGEMM required (`install_deepgemm.sh`)                                                                                                                                                    | vLLM recipe                    |
| Weights fit nowhere                                                                                                 | GLM-5.3 BF16                                                                     | ~1.5 TB: single node only on 8x B300 (SGLang)                                                                                                                                                | SGLang cookbook                |
| Wrong checkpoint loaded                                                                                             | GLM-5.3 vs 5.2                                                                   | Base repo is FP8 for 5.3 and BF16 for 5.2; check `quantization_config` in `config.json`                                                                                                      | TensorRT-LLM guide             |
| Garbage or crash on some CUDA cards                                                                                 | llama.cpp PR builds for GLM-5.3-Flash                                            | Third-party reports: `NVIDIA_TF32_OVERRIDE=0`, `-fa off`; Turing SOFT_MAX failure; illegal memory access report. Unconfirmed; use builds from 2026-10-05 or later.                           | Run-locally guide              |
| `unsupported arch glm5next` or load failure                                                                         | llama.cpp with Unsloth September GGUFs                                           | Mainline uses `glm5-next`; rewrite first shard or convert from BF16                                                                                                                          | community GGUF card            |
| Raw MLX conversion gives bad output                                                                                 | GLM-5.3-Flash on MLX                                                             | Community reports missing `swiglu_limit` clamp and wrong mHC dtype; use builds that patch them (Vontra says mlx-vlm 0.6.3 with GLM5-Next integration, MLX 0.32.0). Unverified by this skill. | Run-locally guide, Vontra card |
| MTP draft too long makes it slower                                                                                  | llama.cpp (Unsloth branch)                                                       | Stop at n=2                                                                                                                                                                                  | Unsloth guide                  |
| Spec decode does not start under PD disaggregation                                                                  | GLM-5.3-Flash on SGLang                                                          | Run PD without speculative flags; keep TP equal on both roles                                                                                                                                | SGLang cookbook                |
| MTP under TensorRT-LLM with NVFP4                                                                                   | GLM-5                                                                            | Not supported; use FP8 for MTP                                                                                                                                                               | TensorRT-LLM guide             |
| MTP gains look small in synthetic benchmarks                                                                        | vLLM                                                                             | Acceptance rate is low on random prompts; benchmark with real traffic                                                                                                                        | vLLM recipe                    |
| Ollama cannot run GLM-5.3-Flash locally                                                                             | Ollama                                                                           | Only the `:cloud` tag was listed on 2026-10-05; do not assume a local pull                                                                                                                   | Run-locally guide              |
