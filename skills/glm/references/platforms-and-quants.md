## llama.cpp (GLM-5.3-Flash)

- Use a build from 2026-10-05 or later. Files must carry the merged `glm5-next` architecture; Unsloth's September files use the earlier `glm5next` name and need a rename, conversion, or Unsloth's `glm5next/upstream` branch (Unsloth guide; community GGUF card).
- Run with `--jinja` and the Unsloth template: `llama-cli --model ...gguf --temp 1.0 --top-p 0.95 --chat-template-kwargs '{"reasoning_effort":"max"}'`.
- Long context: `--cache-type-k q4_1 --cache-type-v q4_1` is Unsloth's example for GLM-5.3 (KV dtypes `f32, f16, bf16, q8_0, q4_0, q4_1, iq4_nl, q5_0, q5_1`).
- MTP with n=2 draft tokens gave up to 3.3x at long context on Unsloth's branch; n above 2 got slower.

## Quant choice

- Datacenter: FP8 is the official and recommended weights; NVFP4 only on Blackwell and not for MTP on TensorRT-LLM.
- Local GGUF: the Unsloth KLD tables say aim for UD-Q4_K_XL or UD-Q5_K_XL (5.3-Flash: 200 / 240 GB, 92% / 94% top-1) where memory allows; UD-IQ1_S keeps about 71%.
