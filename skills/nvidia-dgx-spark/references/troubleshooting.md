# Troubleshooting DGX Spark

> Verified against DGX Spark known issues (Sep 2026), dgx-spark-playbooks (vllm, nccl, connect-two-sparks, llama-cpp), 2026-10-11

| Symptom                                                                   | Cause                                                                                               | Fix                                                                                                                   |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Box freezes or becomes unreachable during a download, build or model load | Shared memory exhausted; no early kill                                                              | earlyoom with `-s 100`, cap jobs, lower engine memory fractions (`memory.md`).                                        |
| `nvidia-smi` says `Memory-Usage: Not Supported`                           | Expected on iGPU                                                                                    | Use `free -h`, `/proc/meminfo`.                                                                                       |
| Engine under- or over-sizes KV cache                                      | `cudaMemGetInfo` ignores reclaimable swap                                                           | Set explicit sizes; compute from `/proc/meminfo`.                                                                     |
| Memory looks stuck in page cache                                          | Cached pages                                                                                        | Diagnostic: `sudo sh -c 'sync; echo 3 > /proc/sys/vm/drop_caches'`, restart the app (NVIDIA workaround).              |
| `exec format error`                                                       | amd64-only image                                                                                    | arm64 or multi-arch, CUDA 13 build.                                                                                   |
| Build says wrong GPU arch                                                 | CMake arch mismatch                                                                                 | `-DCMAKE_CUDA_ARCHITECTURES=121` (llama.cpp playbook uses `121a-real`); NCCL `-gencode=arch=compute_121,code=sm_121`. |
| Containers lose GPU after `systemctl daemon-reload`                       | Toolkit and systemd cgroup driver issue                                                             | Restart the engines.                                                                                                  |
| `ibdev2netdev` shows no Up interface                                      | Cable, port, link                                                                                   | Reseat cable, check approved cable, reboot both nodes.                                                                |
| NCCL test slow or fails                                                   | Different ports on nodes; only one of two interfaces addressed with two cables; wrong interface env | `networking.md`.                                                                                                      |
| Multi-node engine hangs at init or version mismatch                       | Different images behind the same tag                                                                | Compare image IDs (`combos/dual-node-cluster.md`).                                                                    |
| Ray cluster fails in NGC vLLM 26.05                                       | Image ships without `ray` (upstream made it optional)                                               | The playbook installs `ray[default]` before `ray start`; see the `vllm` skill.                                        |
| Slow, reboots or unexpected shutdowns                                     | Non-supplied power adapter                                                                          | Use the 240 W supplied adapter.                                                                                       |
| HDMI display does not wake                                                | Deep sleep after inactivity                                                                         | Press the monitor's physical button.                                                                                  |
| Cannot enter UEFI                                                         | Key timing or keyboard                                                                              | Physically attached keyboard, hold Esc or Del immediately at boot (Esc only on Mac keyboards).                        |
| `docker ps` permission denied                                             | User not in `docker` group                                                                          | `sudo usermod -aG docker $USER && newgrp docker`.                                                                     |
