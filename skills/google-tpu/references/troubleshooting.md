# Troubleshooting

> Verified against Google Cloud TPU docs (software versions, queued resources, GKE TPU how-to), vLLM TPU docs and tpu-inference v0.31.0 source (envs.py), 2026-10-11

Items marked "verify" are inferred from the docs' structure rather than a documented error string; confirm on the live system.

| Symptom                                                   | Likely cause and fix                                                                                                                                                                                                                          |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gcloud compute tpus ...` fails or is missing for TPU7x   | The Cloud TPU API does not support TPU7x. Use GKE or Compute Engine (`provisioning.md`).                                                                                                                                                      |
| Queued resource stays waiting                             | No capacity in the zone. Check state with `queued-resources describe`, try another zone, a reservation or Flex-start (not on TPU7x). Do not create duplicate requests.                                                                        |
| Quota error on create                                     | The project has no TPU quota for that generation, zone or capacity model. Request quota (https://cloud.google.com/tpu/docs/quota); do not retry blindly.                                                                                      |
| `jax.devices()` shows CPU only                            | Wrong runtime image (`v2-alpha-tpuv6e` and friends for the generation), a container without `--privileged`, or a stale `jax`/`libtpu` pairing. Verify: use the pinned `vllm-tpu` install in a clean venv.                                     |
| `vllm serve` hangs on first start                         | Startup precompiles XLA shapes and downloads weights. Give it minutes; read the logs. `SKIP_JAX_PRECOMPILE=1` trades a faster boot for slow first requests.                                                                                   |
| First requests slow, later fast                           | New shapes compile on demand. Warm up with representative lengths, or keep precompilation on. `VLLM_XLA_CHECK_RECOMPILATION=1` finds shapes that recompile.                                                                                   |
| Out of HBM at load or under load                          | Weights plus KV cache exceed HBM of the slice. Lower `--max-model-len`, use a quantization the generation accelerates, or add chips (`generations-and-sizing.md`).                                                                            |
| Model fails to load or gives wrong output                 | Not in the tested matrix, or the plugin lacks that architecture. Check `recommended_models`, try `MODEL_IMPL_TYPE` values, or upgrade `vllm-tpu` to the latest release.                                                                       |
| `Python` or `pip` resolution errors installing `vllm-tpu` | `vllm-tpu 0.31.0` requires Python >=3.10,<3.15 on PyPI and the docs ask for 3.11+. Use a fresh Python 3.12 venv with `uv`.                                                                                                                    |
| Multi-host job crashes at start                           | Wrong topology or node count, workers not all up, or an untested feature combination. Re-check the recipe, `TPU_*` wiring and the feature matrix (multi-host is often untested).                                                              |
| GKE pod `Pending`                                         | Selector mismatch with the node pool (`gke-tpu-accelerator`, `gke-tpu-topology`), missing toleration for the `google.com/tpu` taint, or `google.com/tpu` count not equal to the node's chips. TPU7x also needs the placement policy selector. |
| Gated model download 401                                  | Missing or unaccepted `HF_TOKEN`. Export it from a `0600` file; never paste it into a logged command.                                                                                                                                         |
| Cost still accruing after the run                         | Leftover VM, queued resource, GKE node pool or reservation. Run `teardown.md`.                                                                                                                                                                |
