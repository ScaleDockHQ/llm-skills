# Vercel AI SDK: troubleshooting

> Verified against Vercel AI SDK ai@7.0.137 (@ai-sdk/openai 4.0.91, @ai-sdk/openai-compatible 3.0.67, @ai-sdk/anthropic 4.0.78), 2026-10-11

First reproduce outside the SDK: `BASE_URL=... MODEL=... KEY_FILE=... scripts/probe.sh openai` (or `anthropic`). If curl succeeds and the SDK fails, the cause is URL shape, factory choice or a capability flag.

| Symptom                                                                 | Likely cause and fix                                                                                                                                                                                                  |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 404 on `.../responses`                                                  | `openai("id")` uses the Responses API. Use `openai.chat("id")` or `createOpenAICompatible`.                                                                                                                           |
| 404 on every call                                                       | Missing `/v1` on the OpenAI-compatible or `@ai-sdk/anthropic` base URL; or a doubled `/v1/v1` because it was added twice. Print the final URL from the error's `url` field.                                           |
| `AI_GATEWAY_API_KEY` missing or calls go to Vercel                      | A plain string model id was used. Pass a provider model object (`llm("alias")`).                                                                                                                                      |
| 401 or 403                                                              | Wrong header for the endpoint: `apiKey` sends `x-api-key`, `authToken` sends `Authorization: Bearer`. Check env var names, and that an ambient `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` is not overriding your intent. |
| `model not found` or 400 on `model`                                     | Using the engine's repo id instead of the alias from `/v1/models` (vLLM `--served-model-name`, LiteLLM `model_name`, llama-swap key).                                                                                 |
| `streamText` finishes with empty text and no error                      | Errors are suppressed by default. Add `onError` and read `result.finishReason`; check `/v1/models` and the key.                                                                                                       |
| Streamed `usage` is undefined                                           | Set `includeUsage: true` on `createOpenAICompatible`; the engine must honor `stream_options.include_usage`.                                                                                                           |
| `toolCalls` empty, tool JSON appears in `text`                          | Engine lacks a tool parser: vLLM `--enable-auto-tool-choice --tool-call-parser <name>`, llama-server `--jinja`, Ollama model without tool support. Verify with `scripts/probe.sh`.                                    |
| Tool runs but the answer never uses the result                          | No `stopWhen`; the default is one step. Add `stopWhen: isStepCount(5)`.                                                                                                                                               |
| `stepCountIs is not a function`/deprecated                              | AI SDK 7 renamed it `isStepCount`.                                                                                                                                                                                    |
| `NoObjectGeneratedError` or type validation failed with `Output.object` | Model returned prose or wrapped JSON. Enable `supportsStructuredOutputs` only if the engine enforces `json_schema`; lower temperature; raise `maxOutputTokens` for reasoning models; read `error.text`.               |
| Warning about `responseFormat` unsupported                              | `supportsStructuredOutputs` is false so the schema is not sent. Enable it if the backend supports `json_schema`.                                                                                                      |
| 400 about `developer` role or unknown role                              | OpenAI provider converted `system` to `developer` for an id it treats as a reasoning model. Set `providerOptions.openai.systemMessageMode: "system"`, or rename the alias.                                            |
| 400 `system messages not allowed`                                       | AI SDK 7 rejects `{role:"system"}` in `messages` by default; use the top-level `instructions` option.                                                                                                                 |
| `require is not defined` / ERR_REQUIRE_ESM                              | AI SDK 7 packages are ESM only; use `import` and `"type": "module"`.                                                                                                                                                  |
| Empty content from a reasoning model, finish reason `length`            | Thinking consumed `max_tokens`. Raise `maxOutputTokens` or disable thinking on the engine.                                                                                                                            |
| `<think>` tags in the answer                                            | Engine reasoning parser off; enable it (vLLM `--reasoning-parser`) or wrap with `extractReasoningMiddleware`.                                                                                                         |
| Stream arrives all at once                                              | A proxy buffers SSE. Disable proxy buffering (Nginx `proxy_buffering off`) or use a tunnel that streams.                                                                                                              |
| Timeouts on long prompts                                                | Raise `timeout` or pass `abortSignal`; the default `maxRetries` of 2 will repeat the request.                                                                                                                         |
| Self-signed TLS error (`UNABLE_TO_VERIFY_LEAF_SIGNATURE`)               | Trust the CA with `NODE_EXTRA_CA_CERTS=/path/ca.pem`; do not disable verification globally.                                                                                                                           |
| Browser CORS error                                                      | Do not call the endpoint from the browser; use a server route, or enable CORS on the gateway (and then keys are exposed).                                                                                             |
| Ollama via OpenAI-compatible loses context                              | Ollama's default context is small; raise `OLLAMA_CONTEXT_LENGTH` or the model's `num_ctx` (see the `ollama` skill).                                                                                                   |
