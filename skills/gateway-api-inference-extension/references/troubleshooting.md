# Troubleshooting

> Verified against Gateway API Inference Extension v1.6.2 and llm-d router v0.11.0 (docs, chart README, release notes), 2026-10-11

Capture first: `kubectl describe inferencepool <n>`, `kubectl get gateway,httproute -o yaml` conditions, EPP pod logs.

| Symptom                                                                    | Cause                                                                              | Fix                                                                                                                      |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `no matches for kind "InferencePool"`                                      | GAIE CRDs not installed                                                            | Apply the `v1-manifests.yaml` release asset (`references/install.md`)                                                    |
| Helm install fails on legacy keys                                          | Old GAIE chart values in a new chart                                               | Use the `router.*` keys (`references/updating.md`)                                                                       |
| `helm install --wait` times out with `Available: 1/2` on the EPP           | Active-passive standby replicas are intentionally NotReady                         | `RollingUpdate` with `maxUnavailable >= replicas-1`, or no `--wait`                                                      |
| Requests fail when the EPP restarts                                        | `failureMode: FailClose` (API default)                                             | Use `FailOpen` if serving matters more than routing quality                                                              |
| HTTPRoute `ResolvedRefs=False` or InferencePool not accepted by the parent | Wrong `group`/`kind` in backendRef, cross-namespace ref, gateway lacks support     | Use `group: inference.networking.k8s.io`, `kind: InferencePool`, same namespace; check the gateway implementation's docs |
| EPP finds no endpoints (`ready_endpoints` 0, 503 `rejected-no-endpoints`)  | Selector labels differ from pod labels; pods NotReady; wrong namespace             | Compare `spec.selector` with `kubectl get pods --show-labels`; fix readiness                                             |
| Traffic spreads evenly, no prefix benefit                                  | Engine prefix caching off, or prefix plugin not configured, or active-active EPP   | Enable prefix caching, configure prefix scorer, use active-passive for approximate prefix routing                        |
| EPP cannot scrape metrics                                                  | Wrong `modelServers.type`, auth on the model server metrics, port mismatch         | Set the type to the engine; `curl` the pod `/metrics`; match `targetPorts` and the chart `metricsDataSource` scheme/path |
| Envoy returns 500 or stream drops                                          | Not `FULL_DUPLEX_STREAMED` ext_proc body mode; old LWEPP bug fixed in v1.6.1/1.6.2 | Use the project's Envoy config or a conformant gateway; upgrade to a fixed release                                       |
| Requests time out mid-generation                                           | Route or gateway request timeout too short                                         | Raise `timeouts.request` (chart default 300s) and any LB idle timeout                                                    |
| EPP OOMKilled or CPU throttled                                             | Undersized for rate, output length, or flow-control queues                         | Resize per `references/epp-and-routing.md`; set global `flowControl.maxBytes`                                            |
| `ImagePullBackOff` on the EPP                                              | Old image name `llm-d-inference-scheduler` or missing tag                          | Use `ghcr.io/llm-d/llm-d-router-endpoint-picker` with an existing tag                                                    |
| Queued requests dropped after 60s on a scale-to-zero pool                  | `defaultRequestTTL` default is 60s                                                 | Raise it above cold-start time                                                                                           |
