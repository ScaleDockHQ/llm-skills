# Troubleshooting

> Verified against Modal docs (Servers, Endpoints, Proxy Tokens, Scaling, Volumes, Budgets guides), modal 1.6.1, 2026-10-11

Symptom, cause, fix. Quote the exact status or message when searching Modal's docs.

| Symptom                                                   | Cause                                                                                                                                                | Fix                                                                                                                                                   |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `401` from the proxy, request does not reach your code    | No proxy token, malformed token, or `unauthenticated` not set on a Server meant to be public. Unauthenticated requests do not count for autoscaling. | Send `Authorization: Bearer wk-<id>.ws-<secret>` or `Modal-Key` and `Modal-Secret`. Public only if you intend it: `unauthenticated=True`.             |
| `403` with a valid token                                  | RBAC workspace and the token is not scoped to the App's Environment.                                                                                 | `modal workspace proxy-tokens allow <token-id> <environment>`.                                                                                        |
| `503 Service Unavailable` on the first request            | Server has zero containers; Servers do not queue. A cold start has begun.                                                                            | Retry with backoff, set `min_containers=1`, or add a gateway fallback.                                                                                |
| `503` under load                                          | `max_concurrency` reached on the container.                                                                                                          | Raise `max_concurrency`, lower `target_concurrency` so it scales earlier, or add containers.                                                          |
| Container killed or marked failed at start                | The process never listened on the port within `startup_timeout`, or bound to `127.0.0.1`.                                                            | Bind `0.0.0.0` on the configured `port`, raise `startup_timeout`, read `modal server logs <app>/<server>`.                                            |
| Model downloads on every start                            | HF cache not on a Volume, or writes were never committed.                                                                                            | Mount a Volume at `/root/.cache/huggingface`, call `volume.commit()`, keep `HF_XET_HIGH_PERFORMANCE=1`.                                               |
| Slow start even with cached weights                       | vLLM compilation and CUDA graph capture.                                                                                                             | Mount a vLLM cache Volume, use `FAST_BOOT` (`--enforce-eager`), consider GPU memory snapshots.                                                        |
| CUDA out of memory                                        | Weights plus KV cache exceed VRAM.                                                                                                                   | Larger GPU, lower `--max-model-len` or `--gpu-memory-utilization`, quantised weights (`model-quantization`).                                          |
| `modal deploy` fails: unauthenticated URLs not allowed    | The Environment blocks unauthenticated URLs.                                                                                                         | Leave `unauthenticated` off and use proxy tokens, or ask a manager to change the Environment setting.                                                 |
| Workloads stop mid-month                                  | Workspace budget or spend limit reached.                                                                                                             | Check Usage & Billing and `modal billing summary`; raise the cap only with the user's approval.                                                       |
| `AuthError` or invalid token from the CLI                 | Wrong or expired API token, a conflicting `MODAL_*` env var, or the OAuth and token methods mixed.                                                   | `modal token info`; unset stray `MODAL_TOKEN_*` env vars; `modal token set` or `modal setup`. Service user without Environment access gets No Access. |
| Redeploy resets scaling                                   | `update_autoscaler` changes are not persistent.                                                                                                      | Put durable settings in the decorator.                                                                                                                |
| Container still running after the script exited           | You used `modal deploy`, not `modal run`.                                                                                                            | `modal app stop <app> --yes`.                                                                                                                         |
| LiteLLM `Not Found Error`                                 | `api_base` lacks `/v1`, or wrong `model`.                                                                                                            | Add `/v1`; check `GET /v1/models`.                                                                                                                    |
| Request fails mid-stream after a scale-down or preemption | Servers have no built-in retries.                                                                                                                    | Retry in the client; raise `exit_grace_period` if scale-down cuts long generations.                                                                   |

If an error string is not here, run `modal app logs <app> --since 1h --source stderr` and search Modal's docs for the exact text.
