# Troubleshooting

> Verified against cloudflared 2026.10.0 (docs: common tunnel errors, error 524, connection limits, service tokens), 2026-10-11

First look: `systemctl status cloudflared`, `journalctl -u cloudflared -n 50 --no-pager`, `cloudflared tunnel list`, then the origin directly (`curl -sS http://127.0.0.1:4000/health/liveliness`).

| Symptom                                                        | Cause                                                                                                                   | Fix                                                                                                                                                          |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **HTTP 530 / error 1033**                                      | no healthy cloudflared connector for the tunnel (status Inactive or Down)                                               | start or fix the service; never run via `nohup` or tmux; check outbound port 7844 (`cloudflared tunnel diag`)                                                |
| **HTTP 502** "Unable to reach the origin service"              | tunnel is up, origin is not: service down, wrong protocol (`https://` to an http port), wrong port, or cert not trusted | `curl` the service URL from the host; use `http://127.0.0.1:<port>`; for https origins set `caPool` or `originServerName`; avoid `noTLSVerify` outside tests |
| 502 only for some hosts                                        | service listens on IPv4 loopback, `localhost` resolved to `::1`                                                         | use `127.0.0.1` in `service:`                                                                                                                                |
| **HTTP 524**                                                   | origin sent nothing for 125 s (non-streaming, cold model load, image jobs)                                              | stream, preload models, shorten the job, use a non-Cloudflare path (`tailscale`); Enterprise can raise the timeout                                           |
| 520                                                            | connection idle over 900 s or origin reset                                                                              | keep-alives, retry; check origin logs                                                                                                                        |
| Tokens arrive all at once                                      | response buffered: no `text/event-stream` content type, or another proxy buffers                                        | stream through OpenAI-compatible routes; Caddy `flush_interval -1`; test with `curl -N`                                                                      |
| `ERR_TOO_MANY_REDIRECTS`                                       | origin redirects http to https while cloudflared connects with http                                                     | point the service at `https://` or fix the origin redirect                                                                                                   |
| `ERR_SSL_VERSION_OR_CIPHER_MISMATCH`, `tls: handshake failure` | multi-level subdomain not covered by Universal SSL                                                                      | one-level hostname or an Advanced Certificate                                                                                                                |
| `An A, AAAA, or CNAME record with that host already exists`    | `tunnel route dns` on a taken name                                                                                      | delete the old record or choose another name                                                                                                                 |
| `Tunnel credentials file does not exist or is not a file`      | wrong `credentials-file` path or mode                                                                                   | check the path; under `sudo` `$HOME` is `/root`                                                                                                              |
| `cloudflared service is already installed`                     | only one cloudflared instance may run as a service per machine                                                          | add routes to the existing tunnel, or `sudo cloudflared service uninstall` first                                                                             |
| `x509: certificate signed by unknown authority`                | host lacks CA certificates or a middlebox intercepts TLS                                                                | install `ca-certificates`; inspect the proxy                                                                                                                 |
| `socket: too many open files`                                  | file descriptor limit                                                                                                   | raise ulimit per Cloudflare's system requirements page                                                                                                       |
| `failed to sufficiently increase receive buffer size`          | QUIC UDP buffer (quic-go)                                                                                               | usually harmless; docs show `net.core.rmem_max` tuning                                                                                                       |
| Random disconnects on idle websockets                          | UDP timers or edge maintenance                                                                                          | `protocol: http2`, app keepalives                                                                                                                            |
| Browser shows an Access login instead of JSON on the API       | Access application covers the API hostname                                                                              | remove it, or use a service token with Service Auth (`access-and-auth.md`)                                                                                   |
| 401 or 403 with service token headers                          | token expired, wrong secret, policy action is not Service Auth, app does not include the token                          | check Access authentication logs (failed tokens are logged); create a new token                                                                              |
| Catalog or path rule never matches                             | catch-all above the path rule, or regex mismatch                                                                        | order rules; `cloudflared tunnel ingress rule <url>`                                                                                                         |
| Clients see a thin model list                                  | `/v1/models` goes to the gateway                                                                                        | add the path rule to the Caddy catalog front (`combos/caddy-catalog-front.md`)                                                                               |

## Collect before asking for help

`cloudflared --version`, the sanitized config (`sed -E '/(token|secret|key)/I d'`), 30 lines of `journalctl` without headers (do not use debug level), and `cloudflared tunnel info <name>`.
