# Troubleshooting

> Verified against ROCm 10.1.0 release notes (known and resolved issues), ROCm install guide, vLLM ROCm install docs, 2026-10-11

| Symptom                                                                                        | Cause                                                          | Fix                                                                                                                              |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `Permission denied` on `/dev/kfd` or no ROCm device in a container                             | User not in `render` and `video`, or container missing devices | Add the groups (`usermod -a -G render,video`), run with `--device /dev/kfd --device /dev/dri --group-add=video`; log out and in. |
| `amd-smi: command not found`, `rocm-smi: command not found`                                    | ROCm SMI removed from the standard 10.1 build                  | Install the core packages and use `amd-smi`. `amd-smi --rocm-smi` prints legacy-style output.                                    |
| `rocminfo` shows no `gfx` agent                                                                | Driver not loaded or mismatched                                | `dkms status`, `modinfo amdgpu`, `dmesg \| grep amdgpu`, compare with the matrix, reboot after a driver install.                 |
| `libcudart.so: cannot open shared object file` after `pip install vllm`                        | Wrong Python or index; CUDA wheel installed                    | Use Python 3.12 with the ROCm wheel index, or the `vllm/vllm-openai-rocm` image.                                                 |
| Tensor-parallel hang or `Bus error` in a container                                             | Too little shared memory                                       | Add `--ipc=host` or a large `--shm-size`.                                                                                        |
| MI350 multi-GPU all-reduce returns wrong results                                               | RCCL LL protocol bug (issue #8792)                             | `export NCCL_PROTO=LL128,Simple`.                                                                                                |
| Job hangs and the kernel log shows a retry page fault on Instinct                              | Concurrent memory-heavy jobs with SDMA (issue #8844)           | Run one heavy job per GPU set; the queue can take about 15 minutes to recover; restart the job.                                  |
| MI200 device-to-device copy leaves the destination unchanged                                   | `hipMemcpyDeviceToDeviceNoCU` DMA path                         | Use `hipMemcpyDeviceToDevice`.                                                                                                   |
| MI350X Hugging Face training 6 to 22% slower (BERT, DistilBERT; GPT-2 and RoBERTa with ZeRO 0) | Known issue in 10.1.0 (issue #8878)                            | Expected until fixed; benchmark before blaming your config.                                                                      |
| RAS injection or query fails on MI350P                                                         | Unsupported in 10.1.0                                          | Normal ECC detection and recovery still work.                                                                                    |
| `amd-smi event` hangs on WSL                                                                   | Not supported on WSL                                           | Do not run it; Ctrl+C twice or `kill -9`. WSL2 is Radeon and Ryzen only, technical preview.                                      |
| Engine starts but is slow                                                                      | Wrong attention backend or AITER off                           | Read the startup log for the backend; try `VLLM_ROCM_USE_AITER=1` (default off) per the `vllm` skill.                            |
| Gated model download fails                                                                     | No token                                                       | Export `HF_TOKEN` (never inline), accept the model license.                                                                      |
| Driver build fails after a kernel update                                                       | DKMS rebuild against an unsupported kernel                     | Boot a kernel from the matrix, or install the driver for that kernel.                                                            |

Collect for a vendor ticket: `amd-smi version`, `amd-smi list`, `amd-smi static`, `amd-smi firmware`, `rocminfo`, `uname -r`, `cat /proc/cmdline`, `dmesg -T | grep -i amdgpu`, and the engine log. Remove tokens and hostnames you do not want to share.
