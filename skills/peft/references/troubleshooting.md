# Troubleshooting PEFT

> Verified against PEFT v0.21.2, 2026-10-11

Start with `peft.__version__`, `transformers.__version__` and the full traceback. Entries marked (inferred) come from reading docs, not from reproducing the error.

| Symptom                                                                                      | Cause and fix                                                                                                                                                                                                          |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Training runs, loss moves little, outputs equal the base                                     | `target_modules` partly or fully miss. Check `print_trainable_parameters()` and `peft_model.get_layer_status()`; PEFT only errors if none match. Also verify weights changed after 3+ optimizer steps (`training.md`). |
| `ValueError: ... target modules ... not found in the base model`                             | None of the names match this architecture. Print `named_modules()` or use `target_modules="all-linear"`.                                                                                                               |
| Weights never move (silent)                                                                  | Optimizer or hooks created before the model was on its device. Load, move to device, `get_peft_model`, then create the optimizer.                                                                                      |
| `ValueError: Attempting to unscale FP16 gradients`                                           | fp16 base with `fp16=True`. Cast trainable params to fp32 or `cast_mixed_precision_params`, or use bf16.                                                                                                               |
| `TypeError: LoraConfig.__init__() got an unexpected keyword argument ...` loading an adapter | Adapter saved by a newer PEFT. `pip install -U peft` (source install if saved from source). Fallback: delete the unknown key from `adapter_config.json` only if it is at its default value.                            |
| Poor results from a loaded adapter                                                           | Wrong or different base (revision), random init of layers not saved, adapter in inference mode when you meant to train, or a changed vocabulary. Compare with the base, check `base_model_name_or_path`.               |
| Extended the vocabulary and results are bad                                                  | New embedding rows were not trained or saved. Use `trainable_token_indices` (trainable tokens), or add `modules_to_save` for embeddings/head, and reload with the same resized embeddings.                             |
| Warning about weights "not initialized from the model checkpoint"                            | A head or module was randomly initialized; add it to `modules_to_save` or load a task-specific base.                                                                                                                   |
| Continued training after reload does nothing                                                 | `PeftModel.from_pretrained` defaults to `is_trainable=False`; pass `is_trainable=True`.                                                                                                                                |
| Only one of two adapters trains                                                              | The other is inactive; `model.base_model.set_adapter([...])` before building the optimizer.                                                                                                                            |
| `merge_and_unload` result unchanged or unsupported                                           | Not assigning the return value (it is not in place), the method does not support merging, or quantization forbids it (`adapters-and-merging.md`).                                                                      |
| OOM                                                                                          | Quantize the base, gradient checkpointing, smaller batch/sequence, fewer targets or lower rank (`training.md`).                                                                                                        |
| FSDP no memory savings                                                                       | `fsdp_use_orig_params` must be `false` for PEFT.                                                                                                                                                                       |
| DeepSpeed batch/accumulation mismatch                                                        | Accelerate config `gradient_accumulation_steps` differs from the script's. Match them (inferred from the docs' warning).                                                                                               |
| Loading adapter weights is slow                                                              | Try `low_cpu_mem_usage=True` on load (documented in the "Loading adapter weights is slow" section; avoids initializing weights that are then overwritten).                                                             |
| Batch-norm models give unreproducible results                                                | Batch-norm statistics change in training; see the "Models using batch norm" section of the troubleshooting guide.                                                                                                      |
| Hybrid architecture (Mamba, Jamba, NemotronH) barely trains                                  | Different layer names; target the real module names.                                                                                                                                                                   |

Upstream troubleshooting guide: https://huggingface.co/docs/peft/developer_guides/troubleshooting. Report bugs at https://github.com/huggingface/peft/issues with versions.
