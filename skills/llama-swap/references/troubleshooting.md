# Troubleshooting llama-swap

> Verified against llama-swap v263 (docs/kb troubleshooting, ttl, writing-cmd guides), 2026-10-11

First move for any load problem: copy the model's `cmd`, substitute a real port for `${PORT}`, and run it alone in a shell. If that fails, the problem is the engine, not llama-swap.

| Symptom                                                                     | Likely cause                                                                                                                                                                                | Fix                                                                                      |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Process starts, every request hangs or connection error                     | `proxy` does not match the port the engine listens on (hardcoded port without `proxy`; container `-p ${PORT}:NNNN` right side differs from the in-container port; `--port ${PORT}` missing) | Use `${PORT}` in `cmd` and omit `proxy`, or set `proxy` to the real address.             |
| All requests fail after waiting a long time, model killed just before ready | `healthCheckTimeout` shorter than the load (default 120 s; vLLM compile and cold page cache exceed it)                                                                                      | Raise it (500 to 900); progress reports from `/health` restart the countdown.            |
| Server never looks ready                                                    | Engine has no `/health`                                                                                                                                                                     | Set `checkEndpoint` (`/v1/models` for vLLM style), or `none` as a last resort.           |
| 502 `proxy error: EOF` on a request right after a stream                    | llama-server closes a connection it advertised as keep-alive                                                                                                                                | `disableKeepAlives: true` on that model.                                                 |
| Tool call described in prose, `tools` ignored                               | llama-server build without `--jinja` default (the `capabilities.tools` key only advertises)                                                                                                 | Add `--jinja` to `cmd`.                                                                  |
| Containers survive unload, GPU memory still held                            | No `cmdStop`, or `unloadTimeout` (10 s) shorter than `docker stop`                                                                                                                          | `cmdStop: docker stop ${MODEL_ID}`; raise `unloadTimeout`. Check `docker ps` for strays. |
| Port or GPU busy at load                                                    | Stale process or container from an earlier run, or a manual test container                                                                                                                  | `POST /api/models/unload`, `docker ps`, `nvidia-smi`.                                    |
| Config fails to load, service restart loop                                  | `${env.VAR}` unset in the unit's environment, invalid `logToStdout` value, reserved macro name, duplicate alias                                                                             | Read `journalctl -u llama-swap`; export the variable in the unit.                        |
| Several preloaded models evict each other                                   | Same swapping group                                                                                                                                                                         | Put them in a `swap: false` group or reduce `preload`.                                   |
| HTTP 429                                                                    | `concurrencyLimit` or `globalConcurrencyLimit` hit; rejected, not queued                                                                                                                    | Raise the limit or have the client back off.                                             |
| 401 from clients or UI                                                      | `apiKeys` set                                                                                                                                                                               | Send `Authorization: Bearer`, or `x-api-key`; UI and `/api/` need it too.                |
| Browser client blocked                                                      | CORS                                                                                                                                                                                        | Set `security.cors.allowedOrigins` explicitly.                                           |
| Streaming stops or UI events stall behind nginx                             | Response buffering                                                                                                                                                                          | `proxy_buffering off` for `/api/events` and `/v1/chat/completions`.                      |
| Container unreachable from host with `-p`                                   | `LLAMA_SWAP_LISTEN` bound to loopback in the container                                                                                                                                      | Use `0.0.0.0:8080` in the container, or `--network host`.                                |
| Variant alias loads a second copy                                           | Variant implemented as a second model entry                                                                                                                                                 | Use `filters.setParamsByID` instead.                                                     |
| ComfyUI swaps constantly while the UI is open                               | Websocket and job polling count as requests                                                                                                                                                 | `compat.ignoreWebsockets: true`, use `/comfyui/`, keep `upstream.ignorePaths`.           |

Diagnose with: `curl -s localhost:8080/logs`, the UI Logs page (upstream stream has the real error), and `logLevel: debug`.
