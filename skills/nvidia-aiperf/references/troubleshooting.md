# AIPerf: troubleshooting

> Verified against AIPerf 0.13.0 (CLI options, metrics reference, multi-run, control-hooks and GPU telemetry docs), 2026-10-11

Upstream has no single troubleshooting page for the CLI; entries below come from the cited docs. Entries marked (unverified) are general experience, not upstream statements. Start with `aiperf --version`, the exact command and `artifacts/<run>/logs/aiperf.log`.

| Symptom                                                               | Cause and fix                                                                                                                                                                                                                                                    |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pip install aiperf` fails with a Python version error                | `requires-python >=3.11,<3.14`. Create a venv with 3.11-3.13                                                                                                                                                                                                     |
| Install tries to compile `crick`                                      | Only with the `tdigest` extra on platforms without a wheel (Linux aarch64, Intel macOS): install build tools, or skip the extra                                                                                                                                  |
| Hangs or fails at start while loading a tokenizer                     | The tokenizer is fetched from the Hugging Face Hub. Set `HF_TOKEN` for gated repos, pass a local path, or use `--tokenizer builtin` (no network, counts differ from the real tokenizer)                                                                          |
| 404 or empty responses                                                | `--url` form or `--endpoint-type` does not match the server. The CLI docs say the path is appended to the origin, while upstream YAML examples show a full URL: try the origin only first; `--endpoint` overrides the path; compare with `curl "$URL/v1/models"` |
| 401 or 403                                                            | Server needs a key: `--api-key` (sent as Bearer) or `-H 'Name: value'` for other schemes                                                                                                                                                                         |
| TTFT and ITL are missing                                              | `--streaming` was not set, or the endpoint type cannot stream                                                                                                                                                                                                    |
| `ValueError: Dashboard UI is not supported with sweep/multi-run mode` | Use `--ui simple` or `--ui none` with `--num-profile-runs > 1` or sweeps                                                                                                                                                                                         |
| Token counts look wrong, or the server's OSL differs from `--osl`     | `--osl` is a request cap (`max_completion_tokens`); the model may stop earlier. Compare client counts with the server's `usage` via `--use-server-token-count`. Older servers may need `--use-legacy-max-tokens`                                                 |
| ITL is missing for some requests                                      | ITL needs at least two output tokens                                                                                                                                                                                                                             |
| `tokens/sec/user` is inflated on TensorRT-LLM-like servers            | The server bundles tokens in the first chunk: add `--per-chunk-usage` (server must support `continuous_usage_stats`)                                                                                                                                             |
| Control hook fails on `--reset-kv-cache` or `--server-profiler`       | The server does not mount the route. vLLM needs `VLLM_SERVER_DEV_MODE=1` for the reset and a profiler config for the profiler; SGLang uses `/flush_cache`; TensorRT-LLM has none on `main`                                                                       |
| GPU telemetry empty                                                   | Default mode scrapes DCGM at `localhost:9400` and `9401`; start the DCGM exporter (`dcgm-exporter` skill), pass its URL to `--gpu-telemetry`, or use `--gpu-telemetry pynvml` for local NVIDIA GPUs (`amdsmi` for AMD). `--no-gpu-telemetry` to silence          |
| Server metrics missing                                                | Scraped from `<url>/metrics`; the server must expose it, or pass the URL: `--server-metrics node:9090/metrics`                                                                                                                                                   |
| Reasoning model TTFT much lower than other tools report               | AIPerf counts the first reasoning token as the first token; see `workloads-and-metrics.md`                                                                                                                                                                       |
| Numbers jump between identical runs                                   | No seed, no warmup, too few requests, or client CPU bound. Use `--random-seed`, `--warmup-request-count`, more requests, `--num-profile-runs`; run the client off the server host (unverified as a rule, but standard practice)                                  |
| Run aborted early                                                     | `--failed-request-threshold` tripped (partial results are still aggregated) or the server returned errors: read the log and the error counts                                                                                                                     |
| Latency includes WAN time                                             | Use `--network-latency-automatic` or `--network-latency-mean <ms>`; adjusted values appear as `network_adjusted_*`                                                                                                                                               |
| Artifacts contain private prompts                                     | `inputs.json` and `--export-level raw` store prompts and responses: keep artifact directories private                                                                                                                                                            |

Report bugs with the version, command and log at https://github.com/ai-dynamo/aiperf/issues.
