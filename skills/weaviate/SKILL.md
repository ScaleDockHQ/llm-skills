# Weaviate

Run a single-node Weaviate with authentication on, persistence, a memory plan and an embeddings route through your own OpenAI-compatible endpoint.

**Scope:** Weaviate only: install, size, secure, vectorize through your own embedder, back up, update, troubleshoot, tear down. Kubernetes deployment follows upstream Helm docs and is out of depth here. Embedders are `text-embeddings-inference` and `infinity`.

Work through the steps in order. Load a reference only when a step names it.

## Discover first

Read-only. Do not print API keys.

```bash
command -v docker && docker ps --format '{{.Names}}\t{{.Image}}\t{{.Ports}}' | grep -i weaviate || true
curl -fsS http://127.0.0.1:8080/v1/.well-known/ready -o /dev/null -w 'ready %{http_code}\n' 2>/dev/null
curl -fsS http://127.0.0.1:8080/v1/meta 2>/dev/null | jq '{version,modules:(.modules|keys)}'
ss -ltnp 2>/dev/null | grep -E ':(8080|50051|2112)\b' || true
free -g 2>/dev/null | sed -n 1,2p; df -h . | tail -1
```

With auth on, add `-H "Authorization: Bearer $WEAVIATE_API_KEY"` from your env file (never echo it).

## Decision flow

1. You want vectors generated by the database from text: Weaviate with `text2vec-openai` pointed at LiteLLM or TEI (`references/combos/llm-stack.md`).
2. You prefer to control embedding yourself: create collections with no vectorizer and insert vectors (same flow as other stores).
3. Multi-tenant SaaS-style data: Weaviate multi-tenancy (upstream docs), a differentiator over simpler stores.
4. Simple needs or already on Postgres: `pgvector`; lean single binary: `qdrant`.
5. Size memory first (`references/sizing.md`), including the garbage-collector headroom.
6. Turn off anonymous access before exposing anything.

## Rules

- **Ask before changing the system.** Containers, ports, auth changes, collection deletes and volume removal need approval and an undo path (backup first).
- **Secrets never touch output.** API keys and the vectorizer's key live in a `0600` env file, not in compose files or shell history.
- **Anonymous access is on by default** in the minimal Docker examples (`AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED=true`) and ports publish on all interfaces. Set API-key auth, disable anonymous access, bind to loopback.
- **Both ports matter.** 8080 (REST/GraphQL) and 50051 (gRPC, used by official clients). Expose or proxy both or neither.
- **Fix the embedding model per collection.** A model or dimension change means a new collection and re-vectorization.
- **Limit memory during imports** with `GOMEMLIMIT` or `LIMIT_RESOURCES`, or the kernel can OOM-kill.
- **Back up before upgrades** (`references/updating.md`).
- **Verify upstream.** Image tags, env vars and defaults come from docs read on the writing date (v1.40 line).
