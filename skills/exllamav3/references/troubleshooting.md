# Troubleshooting

> Verified against TabbyAPI main (FAQ, getting-started, config_sample.yml) and ExLlamaV3 v1.6.1, 2026-10-11

Entries marked (experience) come from the repo's earlier operational notes, not upstream docs.

| Symptom                                                                                                   | Cause and fix                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ImportError: DLL load failed while importing exllamav3_ext` (Windows), or `exllamav3_ext` import failure | Wheel does not match Python or CUDA, or a stale torch extension cache. Check the wheel tag (`cu128`/`cp312`), use a venv, then delete `exllamav3_ext` folders in `%LOCALAPPDATA%\torch_extensions\torch_extensions\Cache` (Windows) or `~/.cache/torch_extensions` (Linux) and restart |
| Torch cannot load CUDA / `DLL load failed`                                                                | Install the CUDA toolkit; torch normally brings its own CUDA runtime                                                                                                                                                                                                                   |
| Windows build error mentioning VS build tools                                                             | A dependency lacks a wheel for your Python; install VS Build Tools 17.8 and open an issue upstream                                                                                                                                                                                     |
| Load fails naming `/dev/shm` or a shared-memory limit with tensor parallel, CPU MoE offload or NCCL       | Docker's default 64 MiB. Use `--shm-size=8g` or `--ipc=host` (compose: `shm_size: "8g"`)                                                                                                                                                                                               |
| `exec format error` starting the image on DGX Spark / aarch64                                             | Image is amd64 only. Build from source or use the MiaAI-Lab fork (`install.md`)                                                                                                                                                                                                        |
| Port already in use, server exits                                                                         | TabbyAPI never moves ports. Change `network.port` or free the port; under llama-swap use `${PORT}` and publish `-p 127.0.0.1:${PORT}:5000`                                                                                                                                             |
| Connection refused from the host to a container                                                           | Inside Docker the server must listen on `0.0.0.0` (the image CMD passes `--host 0.0.0.0`; keep it) and the port must be published (`-p 127.0.0.1:5000:5000`)                                                                                                                           |
| Passing flags to the image does nothing or errors                                                         | The entrypoint is `python3`; the first argument must be `main.py`, e.g. `main.py --host 0.0.0.0 --model-name X` (experience, matches Dockerfile)                                                                                                                                       |
| `401`/`403` calling `/v1/model/load`                                                                      | Needs the admin key; an API key cannot load models. `GET /v1/auth/permission` shows the level                                                                                                                                                                                          |
| Keys lost or leaked                                                                                       | Stop the server, delete `api_tokens.yml`, restart to regenerate; update clients                                                                                                                                                                                                        |
| `/v1/models` lists only one model                                                                         | You used an API key (loaded model only); the admin key lists the whole model dir                                                                                                                                                                                                       |
| Model loads then OOM during first request or long prompt                                                  | Lower `chunk_size`, `cache_size` or `max_batch_size`, raise `autosplit_reserve`, quantize the KV cache (`8,8`), pick a lower bpw, or set `warmup: true` so the failure happens at load                                                                                                 |
| `cache_size` rejected                                                                                     | Must be a multiple of 256                                                                                                                                                                                                                                                              |
| Request for another model returns 404 or 503                                                              | `inline_model_loading` is strict: 404 unknown folder, 503 failed load. Dummy names need `use_dummy_models`                                                                                                                                                                             |
| Tool calls come back as plain text                                                                        | No `tool_format` matched the template (startup warns). Set `tool_format` and reasoning tokens explicitly; check the `Response parsing:` log line                                                                                                                                       |
| Thinking text appears in `content` or `reasoning_content` is empty                                        | Set `reasoning_start_token`/`reasoning_end_token` (for example `<think>`/`</think>`), check `start_in_reasoning`, or the model template disables thinking (use `template_vars_default`, e.g. `reasoning_effort` for Hy3)                                                               |
| Startup refuses: sampler preset not found                                                                 | `sampling.override_preset` names a file missing from `sampler_overrides/`                                                                                                                                                                                                              |
| Outputs look noisy with a frontend that sends no sampler values                                           | `safe_defaults` only fills in typical values; set your own overrides, or clear the preset when benchmarking                                                                                                                                                                            |
| Version check fails after manual wheel install                                                            | TabbyAPI enforces its tested exllamav3. Update TabbyAPI or avoid `unsafe_launch` except for debugging                                                                                                                                                                                  |
| `pip install torch` broke ROCm                                                                            | It installs a CPU build. Reinstall the `.[rocm]` extra with AMD indexes (`install.md`)                                                                                                                                                                                                 |
| Source build killed or machine freezes                                                                    | ninja ran too many jobs: `MAX_JOBS=4`; build with serving stopped; on unified-memory hosts cap with a scope                                                                                                                                                                            |
| First import takes minutes                                                                                | JIT build of the extension (`pip install .` isolation); use a wheel or `--no-build-isolation`                                                                                                                                                                                          |
| Triton `Python.h` errors in a container                                                                   | Runtime JIT needs python dev headers; the official cu13 Dockerfile installs `python3.12-dev` for this. Custom images need the same                                                                                                                                                     |
| `embeddings` endpoint missing                                                                             | Requires the extras install (`latest-extras` or `pip install .[extras]`)                                                                                                                                                                                                               |
| Embedding install conflicts with `huggingface_hub`                                                        | The extras pin `huggingface_hub < 1.0` and `sentence-transformers < 4.0`                                                                                                                                                                                                               |
| Slow with CPU MoE offload                                                                                 | Expected; tune `cpu_moe_threads`, prefer `cpu_moe_split_experts` over whole-layer offload, ensure the quant used the default codebook                                                                                                                                                  |
| TP slower than layer split                                                                                | Try `tensor_parallel_backend: nccl` on NVLink, otherwise keep layer split; check `/dev/shm`                                                                                                                                                                                            |
| Drafting makes things slower                                                                              | Low acceptance (high temperature or mismatched model). Try `dynamic_draft: true`, fewer `draft_num_tokens`, or `draft_mode: ngram`, or disable                                                                                                                                         |
| Qwen3-family hybrid model re-prefills the whole prompt on small early edits                               | Recurrent states cannot roll back; reduce `recurrent_checkpoint_interval_pp`                                                                                                                                                                                                           |
| Fork server reachable from the LAN                                                                        | `serve_openai.py` defaults to `--host 0.0.0.0` with no auth: pass `--host 127.0.0.1`                                                                                                                                                                                                   |

## Collecting evidence

```bash
curl -s http://127.0.0.1:5000/health | jq .
python -c "import torch, exllamav3; print(torch.__version__, torch.version.cuda, exllamav3.__version__)"
nvidia-smi --query-gpu=name,driver_version,memory.used,memory.total --format=csv
```

Enable `logging.log_chat_completion_requests` briefly for bug reports, review `logs/debug` for private content before sharing. Ask in the ExLlama Discord or file issues at `turboderp-org/exllamav3` (engine, kernels, conversion) or `theroyallab/tabbyAPI` (server, API, config, Docker).
