# Nemotron known issues

> Verified against vLLM, llama.cpp and Hugging Face GitHub issues and discussions, model cards and TensorFold release notes, 2026-10-11

Status is as of 2026-10-11. "Open" means the issue was open when read; re-check before relying on it. Versions seen:
vLLM v0.31.0 latest (the Lightning card pins `vllm/vllm-openai:v0.27.1`), llama.cpp b11556, SGLang v0.5.21,
TensorRT-LLM v1.3.0rc29 (pre-release).

## TensorFold and Nemotron

TensorFold 1.0.7 qualifies only Lightning (see `platforms-and-quants.md`). Its release notes also mention a Qwen3.5-2B JSON
schema quirk and say "Nemotron writes the same schema correctly"; no open Nemotron-specific bug was found in the 1.0.7 notes.
Qualified does not mean identical to vLLM: TensorFold's exactness claim is relative to its own engine and settings.

## Gaps
