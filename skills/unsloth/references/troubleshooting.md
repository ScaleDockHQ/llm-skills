# Unsloth troubleshooting

> Verified against unslothai/unsloth library 2026.10.3 (docs: saving-to-gguf, saving-to-ollama, fine-tuning guide, multi-GPU; README), 2026-10-11

| Symptom                                                                         | Cause and fix                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Good in Unsloth, gibberish, endless or repeated output in Ollama/llama.cpp/vLLM | Chat template mismatch is the most common cause: use the SAME template at training and inference. Also check the EOS token (wrong EOS gives gibberish on long outputs) and whether the engine adds an unwanted or missing BOS/start token. Upstream says its conversational notebooks force the template. |
| Saving to GGUF or 16-bit crashes (OOM)                                          | Lower `maximum_memory_usage` in the save call (for example 0.5). Stop other GPU/RAM users.                                                                                                                                                                                                                |
| Import errors or odd trainer behavior after upgrading TRL or transformers       | Version skew: Unsloth patches specific versions and pins a TRL range. Reinstall Unsloth in a clean venv and let it choose `transformers`/`trl` (`references/updating.md`).                                                                                                                                |
| Old Unsloth resolved on Windows                                                 | Install `torchao` first, then Unsloth, in a uv venv.                                                                                                                                                                                                                                                      |
| Patches not applied, slower than expected                                       | `import unsloth` before `transformers`/`trl`.                                                                                                                                                                                                                                                             |
| OOM while training                                                              | Shorter `max_seq_length`, `per_device_train_batch_size=1` with more `gradient_accumulation_steps`, QLoRA, `use_gradient_checkpointing="unsloth"`, smaller model.                                                                                                                                          |
| "Latest release" on GitHub is not the library                                   | GitHub releases track Studio/Desktop (`v0.1.x-beta`). Core versions are on PyPI (`pip index versions unsloth` or the PyPI JSON API).                                                                                                                                                                      |
| `merged_4bit` model degrades after re-quantizing                                | 4-bit merges are lossy; merge to 16-bit and quantize from that.                                                                                                                                                                                                                                           |
| Multi-GPU run only uses one GPU                                                 | Launch with `accelerate launch train.py` or `torchrun --nproc_per_node N train.py`; plain `python` is one process.                                                                                                                                                                                        |
| Cannot load a big model on one GPU                                              | `device_map="balanced"` splits it across GPUs.                                                                                                                                                                                                                                                            |
| Studio unreachable, password prompts                                            | See `references/studio.md`; `unsloth studio reset-password`. Exposed servers ask for a password at the terminal.                                                                                                                                                                                          |
| DGX Spark: stock install fails or imports mismatch                              | Use the Spark Dockerfile route; it pins older `transformers`/`trl`/`bitsandbytes` (`references/install.md`). Do not mix with current TRL docs.                                                                                                                                                            |
| Ollama rejects an adapter                                                       | Current Ollama releases reject adapters; merge, convert to GGUF and use `FROM` (`references/combos/gguf-ollama.md`).                                                                                                                                                                                      |

Other places upstream answers questions: https://unsloth.ai/docs, the Discord and r/unsloth (links in the README). File bugs at https://github.com/unslothai/unsloth/issues with `pip show unsloth transformers trl torch` output (no tokens).
