# Phi: known issues and gotchas

> Verified against Phi model cards, GitHub issues and PRs in ggml-org/llama.cpp, vllm-project/vllm and sgl-project/sglang (state read via `gh`), 2026-10-11

| Symptom                                                                          | Cause                                                                                                                                                                                                                                                                                                                                                           | Fix                                                                                                                                                                   |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| System prompt has no effect on Phi-4-reasoning, -plus or reasoning-vision        | Their chat templates hard-code the system prompt and skip `system` messages                                                                                                                                                                                                                                                                                     | Put instructions in the first user message. Source: `tokenizer_config.json` / `chat_template.jinja`                                                                   |
| Reasoning text appears inside `content`                                          | No Phi reasoning parser in vLLM docs or SGLang                                                                                                                                                                                                                                                                                                                  | vLLM: `--reasoning-parser deepseek_r1` (per cards), verify. Otherwise split on `</think>` client-side                                                                 |
| `--enable-reasoning` rejected by `vllm serve`                                    | The Phi-4-reasoning cards show it, current vLLM reasoning docs do not                                                                                                                                                                                                                                                                                           | Drop it and keep `--reasoning-parser deepseek_r1`                                                                                                                     |
| Tool calls come back as plain text `functools[...]`                              | Parser flag missing                                                                                                                                                                                                                                                                                                                                             | Phi-4-mini-instruct only: `--enable-auto-tool-choice --tool-call-parser phi4_mini_json --chat-template examples/tool_chat_template_phi4_mini.jinja` (vLLM)            |
| Tool calling requested on phi-4, reasoning or vision models                      | None of them document a tool format                                                                                                                                                                                                                                                                                                                             | Use Phi-4-mini-instruct, or another model family                                                                                                                      |
| Reasoning model loops or truncates mid-`<think>`                                 | `max_tokens` too low or greedy decoding                                                                                                                                                                                                                                                                                                                         | Use `temperature` 0.8, `top_p` 0.95 (`top_k` 50 for the 14B), `max_tokens` up to 32768                                                                                |
| Phi-4-mini-flash-reasoning will not load in vLLM                                 | `Phi4FlashForCausalLM` is absent from the vLLM v0.31.0 supported-models doc. The V0 PR #20702 merged 2025-07-12, the V1 PR #23996 ("Support Phi4Flash model in V1") was closed unmerged                                                                                                                                                                         | Use Hugging Face Transformers with `mamba-ssm==2.2.4` and `flash_attn==2.7.4.post1` as the card shows (`transformers==4.46.1`), or serve Phi-4-mini-reasoning instead |
| Phi-4-multimodal fails to start in SGLang with a rope-parameter validation error | [SGLang #23909](https://github.com/sgl-project/sglang/issues/23909): `rope_theta` injected into the config trips the model's strict validation. Closed 2026-06-19                                                                                                                                                                                               | Use a current SGLang release (v0.5.21 on 2026-10-11) and retest; else use vLLM                                                                                        |
| vLLM cannot find the `Phi4ForCausalLMV` architecture                             | Microsoft's vLLM README (older) uses a plugin and "vLLM 16.0"; the card says `vllm >= 0.15.2`                                                                                                                                                                                                                                                                   | Current vLLM lists the architecture as built in. Upgrade first; install the plugin from the Microsoft repo only if still unrecognised                                 |
| Phi-4-mini quality drops in llama.cpp when the context is raised                 | [llama.cpp #24823](https://github.com/ggml-org/llama.cpp/issues/24823): LongRoPE factors chosen from the allocated context (`n_ctx_seq`), not the sequence length, so when the allocated context exceeds `original_max_position_embeddings` (4096) short prompts use long-context factors. The issue was closed "not planned" and fix PR #24875 closed unmerged | Allocate only the context you need (4096 for short work), compare with vLLM or Transformers output, and re-check the issue before relying on 128K in llama.cpp        |
| FlashAttention error on V100 or older GPUs                                       | Cards default to flash attention, tested on A100, A6000, H100                                                                                                                                                                                                                                                                                                   | Pass `attn_implementation="eager"` in Transformers (mini-instruct card)                                                                                               |
| Poor non-English output                                                          | English-first training (reasoning, vision)                                                                                                                                                                                                                                                                                                                      | Phi-4-mini-instruct covers 23 languages; reasoning and vision cards say English only                                                                                  |
| Wrong API calls in generated code                                                | Training data is mostly Python with common stdlib packages (cards)                                                                                                                                                                                                                                                                                              | Verify API usage; do not rely on non-Python code generation                                                                                                           |
| Vision model answers differently with and without reasoning                      | It chooses `<think>` or `<nothink>` itself                                                                                                                                                                                                                                                                                                                      | Force with the `<think>` / `<nothink>` suffix on the generation prompt. Card benchmarks show forced modes are not uniformly better                                    |
| Multimodal GGUF asked for patched llama.cpp                                      | Old community card text                                                                                                                                                                                                                                                                                                                                         | PR #20168 merged 2026-03-11; use a current build with the model plus `mmproj` GGUF                                                                                    |

## Content limits stated by Microsoft

- Phi-4-reasoning(-plus), mini-reasoning and mini-flash-reasoning: cards say the reasoning models are designed and tested
  for math reasoning (the 14B cards also cover science and code). Do not expect general knowledge depth from the 3.8B models;
  cards recommend RAG for factual use.
- Reasoning-vision: not for medical, legal or financial advice, and not for consequential allocation decisions without extra
  assessment (card section 2.2).
- All cards: long conversations can get repetitive, so limit turns.
