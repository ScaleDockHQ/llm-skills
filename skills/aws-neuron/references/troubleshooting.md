# Troubleshooting

> Verified against Neuron docs (NxD Inference troubleshooting, Neuron DLAMI User Guide), vllm-neuron release-0.24.0.1.1.0 setup and features guides, Neuron SDK 2.32.0, 2026-10-11

| Symptom                                                      | Cause and fix                                                                                                                                                                                              |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `neuron-ls` shows no devices                                 | Not a Neuron instance type, driver not installed or loaded, or container started without `--device=/dev/neuronN`. Check `ls /dev/neuron*` and `dmesg \| grep neuron`; reboot after a fresh driver install. |
| Plugin does not load the Neuron platform                     | Wrong venv or vLLM installed after the plugin. Activate the DLAMI venv, check `pip show vllm-neuron`, reinstall the plugin so versions align.                                                              |
| `vllm-neuron` 0.24.x on Inf2 or Trn1 fails or is unsupported | That line is Trn2 and Trn3 only. Use the NxD Inference line (plugin 0.5.3) on Inf2 and Trn1 (`vllm-neuron.md`).                                                                                            |
| Python version errors                                        | Plugin needs Python 3.11 or later. The DLAMI venv ships a compatible Python.                                                                                                                               |
| `ImportError: ... GLIBC_2.35 not found` on Amazon Linux 2023 | AL2023 DLAMIs do not support PyTorch 2.9+, so no vLLM env. Use an Ubuntu 24.04 DLAMI.                                                                                                                      |
| First start takes minutes, model "hangs" at load             | First-time compilation per bucket. Wait, keep `VLLM_CACHE_ROOT` on local NVMe, reduce buckets while developing, pre-compile for production with `NEURON_COMPILED_ARTIFACTS`.                               |
| Compile fails or the instance runs out of host memory        | Large model or many buckets. Reduce buckets or `--max-model-len`/`--max-num-seqs`, or compile on a bigger host or CPU instance.                                                                            |
| First requests slow on Trn2 (NxD Inference line)             | Warm-up is skipped by default on Trn2. Send dummy requests before taking traffic, or set `{"skip_warmup": false}` in `override-neuron-config` where supported.                                             |
| Wrong or degraded accuracy                                   | The compiler auto-casts to BF16 by default. NxD Inference docs suggest `--auto-cast=none` via compiler args (slower, more memory). Compare against a reference.                                            |
| Unsupported sampling parameters ignored (NxD Inference line) | On-device sampling supports only `temperature`, `top_k`, `top_p`. Use CPU sampling if you need others.                                                                                                     |
| `createBackend: unsupported backend 'LIBFABRIC'`             | Disaggregated inference missing `libfabric.so.1` or `libcuda.so.1` stub. Follow the plugin setup guide; the `CUDA driver is a stub library (Error 34)` warning alone is harmless.                          |
| LNC mismatch errors or unexpected core counts                | Runtime `NEURON_LOGICAL_NC_CONFIG` must match the compile-time setting; only 1 or 2 are valid and only on Trn2 and Trn3. Recompile after changing it.                                                      |
| Model not in the tested list                                 | Plugin line lacks that architecture. Check the README tables; onboarding guides exist for custom models (NxD Inference) but are engineering work.                                                          |
| Gated model download 401                                     | Missing `HF_TOKEN` or unaccepted license. Export from a `0600` file; never echo it.                                                                                                                        |
