# torchao troubleshooting

> Verified against torchao v0.18.0 (README, compatibility table, Transformers torchao guide, release notes), 2026-10-11

| Symptom                                                                                                                                              | Cause and fix                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Fatal Python error: Aborted` on `import torchao`                                                                                                    | torchao built for a different torch. Match versions with the table in `install.md`; reinstall both from the same index.                                                                                                           |
| Import errors on removed names (`AffineQuantizedTensor`, `TensorCoreTiledLayout`, `PlainLayout`, `Quantizer`, `insert_observers_`, `NF4Tensor` path) | 0.18.0 removed the v1 tensor-subclass and layout system and moved `NF4Tensor` to `torchao.quantization.quantize_.workflows`. Port to the v2 configs or pin an older torchao with its torch.                                       |
| `Int4WeightOnlyOpaqueTensorConfig` not found                                                                                                         | Renamed to `PrototypeInt4WeightOnlyConfig` (from `torchao.prototype.quantization.int4`).                                                                                                                                          |
| `TorchAoConfig("int4_weight_only")` fails                                                                                                            | String API removed (torchao 0.15.0+ with Transformers); pass an `AOBaseConfig` object.                                                                                                                                            |
| Quantized model slower than bf16                                                                                                                     | Compile is off, shapes too small, or the config does not suit the GPU (int8 weight-only was slower than bf16 on H100 in upstream benchmarks). Use `cache_implementation="static"` or `torch.compile`; try float8 dynamic on H100. |
| Recompiles on every `generate`                                                                                                                       | Static cache recompiles when batch size or `max_new_tokens` changes; fix them or pass `disable_compile=True`.                                                                                                                     |
| Float8 config errors on A100                                                                                                                         | Float8 dynamic needs compute capability 8.9+; use int8 or int4.                                                                                                                                                                   |
| CPU int4 fails                                                                                                                                       | Requires torchao 0.15.0 or newer and the prototype config.                                                                                                                                                                        |
| FP8 optimizer errors                                                                                                                                 | Needs compute capability 8.9+ on CUDA.                                                                                                                                                                                            |
| vLLM cannot load a torchao checkpoint                                                                                                                | Version skew between vLLM and torchao; try the pair upstream tested, set `--tokenizer` for `pytorch/*` repos, and `VLLM_DISABLE_COMPILE_CACHE=1` as in the upstream example.                                                      |
| Nightly mismatch                                                                                                                                     | Nightly torchao needs nightly torch; install both from the nightly index.                                                                                                                                                         |

If still stuck, open an issue at https://github.com/pytorch/ao/issues with `pip freeze` for torch, torchao, transformers.
